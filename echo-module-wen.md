# ECHO 平台「文」模块设计

## 概述
「文」模块是ECHO平台的文字创作核心，支持从短篇随笔到长篇小说的全类型文字内容创作。采用树形结构管理章节，支持多人协作，并与ECHO其他资产深度集成。

---

## 1. 内容分类体系

### 1.1 五大核心类别

| 类别 | 定位 | 内容特征 | 商业模式 |
|------|------|----------|----------|
| **小说** | 虚构叙事创作 | 长篇/中篇/短篇、连载模式、世界观构建 | 订阅/打赏/改编授权 |
| **随笔** | 个人思考与感悟 | 碎片化、即时性、情感表达 | 免费+打赏/付费专栏 |
| **历史** | 非虚构历史叙述 | 史料考据、人物传记、历史评论 | 付费阅读/知识付费 |
| **文学** | 纯文学与艺术写作 | 诗歌、散文、实验性文本 | 出版代理/打赏 |
| **知识** | 结构化知识输出 | 教程、指南、百科、研究报告 | 付费课程/授权 |

#### 核心功能
- **无限层级**：支持卷/章/节/回目无限嵌套
- **拖拽排序**：可视化调整章节顺序与层级关系
- **大纲视图**：一键切换大纲/树形/时间线视图
- **章节状态**：草稿/编辑中/审核中/已发布/已归档
- **字数统计**：实时统计字数、阅读时长预估

## 4. 数据模型

### 4.1 核心实体

```typescript
// 作品
interface Work {
  id: string;
  title: string;
  authorId: string;
  category: 'novel' | 'essay' | 'history' | 'literature' | 'knowledge';
  subCategories: string[];
  status: 'draft' | 'serializing' | 'completed' | 'archived';
  metadata: {
    coverImage?: string;
    summary: string;
    tags: string[];
    wordCount: number;
    readingTime: number;
    createTime: Date;
    updateTime: Date;
  };
  chapters: Chapter[];
  collaborators: Collaborator[];
  license: License;
}

// 章节
interface Chapter {
  id: string;
  workId: string;
  parentId?: string;           // 树形结构父节点
  order: number;
  title: string;
  content: string;             // Markdown
  status: 'draft' | 'editing' | 'review' | 'published';
  version: Version[];
  references: AssetReference[];
  citations: Citation[];       // 谁引用了本章
  metadata: {
    wordCount: number;
    createTime: Date;
    updateTime: Date;
    publishTime?: Date;
  };
}

// 版本
interface Version {
  id: string;
  chapterId: string;
  content: string;
  authorId: string;
  changeType: 'create' | 'edit' | 'revert';
  changeSummary: string;
  timestamp: Date;
}

// 协作
interface Collaborator {
  userId: string;
  role: 'owner' | 'editor' | 'commenter' | 'suggester';
  permissions: {
    canEdit: boolean;
    canDelete: boolean;
    canInvite: boolean;
    canPublish: boolean;
  };
  joinedAt: Date;
}
```

### 5.1 核心接口

```typescript
// 作品管理
POST   /api/works                    // 创建作品
GET    /api/works/:id                // 获取作品
PUT    /api/works/:id                // 更新作品
DELETE /api/works/:id                // 删除作品

// 章节管理
POST   /api/works/:id/chapters       // 创建章节
GET    /api/chapters/:id             // 获取章节
PUT    /api/chapters/:id             // 更新章节
DELETE /api/chapters/:id             // 删除章节
POST   /api/chapters/:id/reorder     // 调整顺序

// 协作
POST   /api/works/:id/collaborators  // 添加协作者
PUT    /api/collaborators/:id        // 更新权限
DELETE /api/collaborators/:id        // 移除协作者

// 引用
POST   /api/chapters/:id/references  // 添加引用
GET    /api/works/:id/citations      // 获取被引用

// 收益
GET    /api/revenue/summary          // 收益汇总
```
