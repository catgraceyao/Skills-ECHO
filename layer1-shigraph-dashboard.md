### 1.2 "势"的量化定义

**"势"(Shi)** 是 ECHO 协议的核心概念，代表资产在网络中的综合影响力与价值潜力。

```
势(Shi) = f(时间维, 空间维, 关系维) × 动态调整因子
```

#### 核心概念层级

```
┌─────────────────────────────────────────────────────────────────┐
│                        势位(Shi Position)                        │
│                      资产在三维空间中的坐标                        │
├──────────────────┬──────────────────┬───────────────────────────┤
│    时间维(T)     │    空间维(S)     │       关系维(R)           │
│   生命历史深度   │   分布广度       │     连接强度             │
├──────────────────┼──────────────────┼───────────────────────────┤
│ • 版本迭代频率   │ • 存储可靠性     │ • 被引用数量             │
│ • 历史活跃度     │ • 跨链分布       │ • 衍生作品数             │
│ • 生命周期阶段   │ • 存证完整度     │ • 网络中心性             │
│ • 时间衰减曲线   │ • 冗余备份数     │ • 影响力辐射范围         │
└──────────────────┴──────────────────┴───────────────────────────┘
```

#### "势"的数学定义

**基础公式**:
```
Shi_score = α × T_score + β × S_score + γ × R_score

其中:
- α + β + γ = 1 (维度权重, 默认 α=0.35, β=0.25, γ=0.40)
- T_score ∈ [0, 100] 时间维度得分
- S_score ∈ [0, 100] 空间维度得分  
- R_score ∈ [0, 100] 关系维度得分
- Shi_score ∈ [0, 100] 综合势位得分
```

**势位等级划分**:
```
┌─────────────┬──────────────┬─────────────────────────────────────┐
│   等级      │   得分区间   │              特征描述               │
├─────────────┼──────────────┼─────────────────────────────────────┤
│  ★ 原质     │   0-20      │ 初生/休眠状态，几乎无网络连接       │
│  ★★ 萌芽    │  20-40      │ 初步建立，有少量引用和迭代          │
│  ★★★ 成长   │  40-60      │ 活跃发展中，形成稳定引用网络        │
│  ★★★★ 成熟  │  60-80      │ 生态核心节点，被广泛引用和衍生      │
│  ★★★★★ 巅峰 │  80-100     │ 行业标杆，影响力辐射整个网络        │
└─────────────┴──────────────┴─────────────────────────────────────┘
```

### 1.3 三维编织的可视化策略

**核心隐喻**: 将资产想象为星系中的恒星，其引力场（势）影响着周围的星体（引用/衍生资产）。

#### 可视化哲学

1. **时间维**: 螺旋时间轴（Spiral Timeline）
   - 参考: 古代玛雅历法 + 现代基因螺旋结构
   - 意义: 时间不是直线，而是循环上升的发展
   - 视觉: 从中心向外螺旋展开，新版本在更外层

2. **空间维**: 拓扑地图（Topology Map）
   - 参考: 塞尔达荒野之息地图 + 地铁线路图
   - 意义: 展示资产在不同"大陆"（链/存储层）的分布
   - 视觉: 等高线地形图，不同颜色代表不同"海拔"（可靠性）

3. **关系维**: 力导向网络（Force-Directed Graph）
   - 参考: MIT Media Lab 的 Observable 网络可视化
   - 意义: 直观展示资产间的引力关系
   - 视觉: 节点大小=势位得分，连线粗细=引用强度

#### 3D/2D 切换策略

```
┌─────────────────────────────────────────────────────────────────┐
│                    默认视图: 2.5D 混合视图                       │
├─────────────────────────────────────────────────────────────────┤
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐          │
│  │   时间轴     │  │   网络图     │  │   拓扑图     │          │
│  │  (侧栏/底部) │  │  (主视觉区)  │  │  (悬浮卡片)  │          │
│  └──────────────┘  └──────────────┘  └──────────────┘          │
├─────────────────────────────────────────────────────────────────┤
│  切换模式:                                                      │
│  • 普通模式: 2D 平面，性能优先，信息密度高                     │
│  • 沉浸模式: 3D 空间，WebGL 渲染，适合展示关系                 │
│  • VR/AR 模式: 空间计算，未来扩展                              │
└─────────────────────────────────────────────────────────────────┘
```

**布局算法**:

1. **力导向布局 (Force-Directed)**
   - 节点间引力: `F_attraction = k × (shi_i × shi_j) / d²`
   - 节点间斥力: `F_repulsion = c / d`
   - 中心引力: `F_center = m × d`
   - 最佳用于: 探索关系结构

2. **层次布局 (Hierarchical)**
   - 按引用层级排列: 根资产在上，衍生在下
   - 最佳用于: 理解资产谱系

3. **径向布局 (Radial)**
   - 当前资产在中心，按势位分层向外辐射
   - 最佳用于: 展示影响力范围

## 三、"势"的计算模型

### 3.1 时间维度得分 (T_score)

```
T_score = w₁ × T_version + w₂ × T_activity + w₃ × T_lifecycle + w₄ × T_decay

其中: w₁=0.30, w₂=0.25, w₃=0.25, w₄=0.20
```

#### 3.1.1 版本迭代得分 (T_version)

```
T_version = min(100, base_score + iteration_bonus)

base_score = 10  # 基础分

iteration_bonus = Σ(iteration_valueᵢ × recency_weightᵢ)

其中:
- iteration_value: 每次迭代的价值评估
  • 重大更新 (major): +15分
  • 次要更新 (minor): +8分
  • 补丁更新 (patch): +3分
  
- recency_weight: 时间衰减权重
  recency_weight = exp(-λ × days_ago)
  λ = 0.01 (半衰期约69天)
```

#### 3.1.2 历史活跃度得分 (T_activity)

```
T_activity = 100 × (1 - exp(-activity_rate / k))

activity_rate = events_last_90_days / 90

其中 k = 0.5 (调节参数)

活跃度事件包括:
- 版本发布: +1.0
- 被引用: +0.5
- 交易: +0.3
- 社区互动: +0.2
```

#### 3.1.3 生命周期得分 (T_lifecycle)

```
T_lifecycle = 100 × lifecycle_factor

lifecycle_factor 基于资产年龄和活跃度:
- 新生儿期 (0-30天): 0.6 + 0.4 × (days/30)
- 成长期 (30-180天): 1.0
- 成熟期 (180-365天): 0.9 + 0.1 × recency_score
- 稳定期 (365天+): 0.8 + 0.2 × recency_score

recency_score = events_last_30_days / max_events_baseline
```

#### 3.1.4 时间衰减修正 (T_decay)

```
T_decay = 100 × (1 - decay_penalty)

decay_penalty = max(0, 1 - activity_last_30_days / activity_baseline)

如果长期无活动 (>90天):
decay_penalty = 0.3 + 0.7 × (1 - exp(-days_inactive / 180))
```

### 3.2 空间维度得分 (S_score)

```
S_score = w₁ × S_reliability + w₂ × S_distribution + w₃ × S_integrity + w₄ × S_redundancy

其中: w₁=0.30, w₂=0.25, w₃=0.25, w₄=0.20
```

#### 3.2.1 存储可靠性得分 (S_reliability)

```
S_reliability = Σ(storage_scoreᵢ × weightᵢ)

存储层评分:
- Arweave (永久存储): 20分
- Ethereum mainnet: 18分
- IPFS (多节点): 15分
- Filecoin: 16分
- Polygon/BSC等侧链: 12分
- 中心化云存储: 8分
- 本地存储: 5分

weightᵢ = storage_sizeᵢ / total_size
```

#### 3.2.2 跨链分布得分 (S_distribution)

```
S_distribution = 100 × min(1, chain_diversity / optimal_chains)

chain_diversity = Σ(chain_valueᵢ)

chain_value 计算:
- 每个独特的链: +0.3
- 每个链上有活跃数据: +0.2
- 跨链桥接存在: +0.1 × bridge_count

optimal_chains = 3 (理想分布链数)
```

#### 3.2.3 存证完整度得分 (S_integrity)

```
S_integrity = 100 × (1 - Σ(missing_parts × severityᵢ) / total_parts)

severity:
- 元数据缺失: 0.2
- 内容哈希缺失: 0.5
- 签名缺失: 0.3
- 时间戳缺失: 0.1
```

#### 3.2.4 冗余备份得分 (S_redundancy)

```
S_redundancy = 100 × min(1, redundancy_factor)

redundancy_factor = unique_copies / min_required_copies

min_required_copies = 3 (最小建议备份数)

额外奖励:
- 地理分布冗余 (不同大洲): +10%
- 存储类型多样化: +10%
```

### 3.3 关系维度得分 (R_score)

```
R_score = w₁ × R_citations + w₂ × R_derivatives + w₃ × R_centrality + w₄ × R_influence + w₅ × R_quality

其中: w₁=0.25, w₂=0.20, w₃=0.20, w₄=0.20, w₅=0.15
```

#### 3.3.1 被引用数量得分 (R_citations)

```
R_citations = 100 × (1 - exp(-citation_count / k))

其中 k = 50 (50次引用达到63%得分, 150次接近满分)

引用质量加权:
weighted_citations = Σ(citation_weightⱼ)

citation_weight 基于引用者势位:
- 巅峰级 (80-100): 2.0
- 成熟级 (60-80): 1.5
- 成长级 (40-60): 1.0
- 萌芽级 (20-40): 0.6
- 原质级 (0-20): 0.3
```

#### 3.3.2 衍生作品数量得分 (R_derivatives)

```
R_derivatives = 100 × min(1, derivative_score / max_score)

derivative_score = Σ(derivative_valueᵢ)

derivative_value:
- 直接衍生 (fork/remix): +2.0
- 灵感衍生 (inspired by): +1.0
- 引用衍生 (cited): +0.5

额外奖励:
- 衍生作品本身有衍生: +0.3 × 次级衍生数
```

#### 3.3.3 网络中心性得分 (R_centrality)

```
R_centrality = 100 × (PageRank_score / max_possible_pagerank)

使用个性化 PageRank 算法:
PR(v) = (1-d)/N + d × Σ(PR(u) / L(u))

其中:
- d = 0.85 (阻尼系数)
- N = 网络中资产总数
- L(u) = 资产u的出度

中心性等级:
- 桥接节点 (连接不同社群): ×1.3
- 权威节点 (被多个权威引用): ×1.2
```

#### 3.3.4 影响力辐射得分 (R_influence)

```
R_influence = 100 × (1 - exp(-influence_depth × influence_breadth / k))

influence_depth = 影响力传播的最深层数 (max 5)
influence_breadth = 各层平均覆盖资产数

k = 100 (调节参数)

领域跨越奖励:
- 每跨越一个领域: +5分 (max 20分)
```

#### 3.3.5 引用质量得分 (R_quality)

```
R_quality = 100 × quality_ratio

quality_ratio = high_quality_citations / total_citations

高质量引用定义 (满足任一):
- 引用者势位 > 60
- 引用包含深度分析 (>500字)
- 引用产生衍生内容
- 引用带来显著流量 (>100访问)
```

│                    势位综合计算公式                              │

│                                                                 │
│  最终得分: Shi_score ∈ [0, 100]                                │
│  保留一位小数，四舍五入                                          │

└─────────────────────────────────────────────────────────────────┘

### 5.2 网络图布局算法

#### 5.2.1 力导向布局 (Force-Directed)

```
┌─────────────────────────────────────────────────────────────────┐
│                    力导向布局参数                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  物理模型:                                                      │
│  ─────────────────────────────────────────────────────────────  │
│                                                                 │
│  1. 节点间引力 (Spring Force)                                   │
│     F_attraction = k × (shi_i × shi_j) / d²                   │
│     • k = 0.05 (引力常数)                                       │
│     • shi_i, shi_j = 节点势位                                   │
│     • d = 节点间距离                                            │
│                                                                 │
│  2. 节点间斥力 (Coulomb Repulsion)                              │
│     F_repulsion = -c / d                                        │
│     • c = 1000 (斥力常数)                                       │
│     • 防止节点重叠                                              │
│                                                                 │
│  3. 中心引力 (Center Gravity)                                   │
│     F_center = m × d                                            │
│     • m = 0.01 (中心引力系数)                                   │
│     • 防止网络飘出视野                                          │
│                                                                 │
│  4. 阻尼 (Damping)                                              │
│     velocity *= (1 - damping)                                   │
│     • damping = 0.1 (快速收敛)                                  │
│                                                                 │
│  迭代参数:                                                      │
│  • 最大迭代: 300                                                │
│  • 收敛阈值: 节点平均移动 < 0.01                                │
│  • 温度衰减: 模拟退火，初期大幅移动，后期微调                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
