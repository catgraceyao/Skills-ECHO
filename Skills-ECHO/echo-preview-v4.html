四权与算场模型耦合：
使用权 → D（扩散系数）：用权越高 → 传播越广 → 被引用越多 → 虹吸增益越大
扩展权 → K（方法多样性）：扩权越高 → 可被编排进越多方法 → 生态复杂度越高
衍生权 → 改编/分叉概率：衍权越高 → 二次创作越活跃 → 生态多样性越高
收益权 → 分配比例：益权越高 → 创作者激励越强 → 马太效应可能加剧

四权独立配置：高用权+低扩权 = 开放可见但不可编排（只能看，不能集成）
低用权+高扩权 = 私密但方法可复用（自己用，但方法开源）
