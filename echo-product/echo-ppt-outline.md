### **Slide 4: 四权力 — 资产的基因密码**

**四权 = 元亨利贞**:

| 权力 | 卦德 | 本质 | 八档演化 | 技术表达 |
|------|------|------|----------|----------|
| **用** (使用) | 元 | 创始 | 禁→锁→借→阅→采→用→持→归 | 调用权限 |
| **扩** (扩展) | 亨 | 通达 | 独→友→圈→域→网→链→元→道 | 组合权限 |
| **衍** (衍生) | 和 | 生化 | 止→赏→评→引→混→融→造→生 | 改编权限 |
| **益** (收益) | 贞 | 守恒 | 藏→孤→稀→罕→流→众→源→道 | 分润比例 |

**基因码公式**:
```
基因码 = (用 << 9) | (扩 << 6) | (衍 << 3) | 益
       = 12bit = 4096 种基础配置
```

**权力依赖**:
```
用 = 禁(0)  →  扩 = 独(0)，衍 = 止(0)，自动锁定
用 > 0      →  扩、衍自由配置
```

**视觉**: DNA 双螺旋结构，四权作为碱基对

### **Slide 5: 技能即资产 — Skills ECHO化**

**核心循环**:
```
开发者设计 Skill
    ↓
配置四权（用/扩/衍/益）
    ↓
铸造为 ECHO（上链确权）
    ↓
进入势场（被用户发现）
    ↓
被 Agent Claw 调用
    ↓
产生收益 + 势位提升
```

**Skill 配置示例**:

```yaml
skill:
  name: "赛博禅意图像生成"
  author: "0xAlice..."
  
  # 四权配置（基因码）
  rights:
    use: 6      # 用：可商用
    expand: 4   # 扩：可跨域组合
    derive: 5   # 衍：可融合改编
    benefit: 3  # 益：30%收益归作者
  
  # 依赖声明
  dependencies:
    - skill: "base-diffusion-v2"
      share: 10%  # 10%收益分配给上游
    - skill: "zen-style-lora"
      share: 5%
  
  # 沙箱配置
  sandbox:
    type: medium  # 中量级（gVisor）
    resources:
      gpu: "A10G"
      memory: "8GB"
```

**视觉**: Skill 卡片，显示四权配置、势位、价格、依赖图谱

### **Slide 7: 组合创作 — 多技能编排**

**核心机制**:
> 输出结果可能是多个 Skills 组合，形成「创作谱系」

**组合模式**:

| 模式 | 说明 | 示例 |
|------|------|------|
| **串行** | A的输出作为B的输入 | 文案 → 配音 → 视频 |
| **并行** | 多个技能同时执行 | 音乐+图像+代码同时生成 |
| **条件** | 根据中间结果选择 | 检测情绪 → 选择风格 |
| **循环** | 迭代优化 | 生成→评估→重生成 |

**编排示例 — 「赛博朋克概念专辑」**:
```yaml
workflow:
  name: "赛博朋克概念专辑"
  
  steps:
    - skill: "world-builder"
      output: "世界观文档"
      
    - skill: "character-designer"
      input: ["世界观文档"]
      output: "角色设定图"
      
    - parallel:
        - skill: "music-composer"
          input: ["世界观文档"]
          output: "主题曲"
          
        - skill: "visual-album-artist"
          input: ["世界观文档", "角色设定图"]
          output: "专辑封面"
          
    - skill: "lyric-writer"
      input: ["主题曲", "世界观文档"]
      output: "歌词"
      
    - skill: "video-director"
      input: ["主题曲", "歌词", "角色设定图"]
      output: "MV"
```

**视觉**: 流程图 + 依赖关系图谱

### **Slide 10: 卦象命运 — 从四权到64卦**

**梅花易数起卦**:
```
上卦 = 用 mod 8    (天道，创造与传播的合力)
下卦 = 扩 mod 8    (地道，生根与延展的承载)
动爻 = (衍+益) mod 6 + 1  (人道，变化之机)

卦序 = 上卦 × 8 + 下卦 + 1  (1-64)
```

**本卦 → 变卦**:
- **本卦**: 当下之态
- **变卦**: 未来之势
- **动爻**: 变化之机

**示例**:
```
Skill "赛博禅意生成器"
├── 用 = 6 (商用)
├── 扩 = 4 (跨域)
├── 衍 = 5 (融合)
├── 益 = 3 (30%分成)
├── 上卦 = 6 mod 8 = 6 → 兑(泽)
├── 下卦 = 4 mod 8 = 4 → 震(雷)
├── 本卦 = 泽雷随（随从、顺应）
├── 动爻 = (5+3) mod 6 + 1 = 3
└── 变卦 = 泽火革（变革、创新）

解读：当前处于「顺应需求」之势，变化之机在第三爻，
      预示向「革故鼎新」转化
```

**视觉**: 八卦符号 + 卦象变化动画

### **Slide 11: 气数与九变势 — 资产的生命节律**

**气数计算**:
```javascript
// Logistic 混沌映射
function calculateQi(geneCode, timestamp) {
  const r = 3.99;  // 混沌临界
  let x = (geneCode % 9973) / 9973;
  
  const iterations = 50 + (timestamp % 50);
  
  for (let i = 0; i < iterations; i++) {
    x = r * x * (1 - x);  // 蝴蝶效应
  }
  
  return x;  // 0-1 之间
}
```

**气数等级**:

| 气数 | 等级 | 状态 | 诗意 |
|:----:|:----:|:----:|------|
| 0.00-0.25 | dormant | 沉寂 | 潜龙勿用，静待时机 |
| 0.25-0.50 | gentle | 温润 | 见龙在田，德施普也 |
| 0.50-0.75 | vigorous | 蓬勃 | 终日乾乾，反复道也 |
| 0.75-1.00 | fierce | 凛冽 | 或跃在渊，进无咎也 |

**九变势**:
```
1/9: 初九 · 潜龙勿用  → 初生，尚未显露
2/9: 九二 · 见龙在田  → 渐显，开始被看见
3/9: 九三 · 终日乾乾  → 勤勉，持续被使用
4/9: 九四 · 或跃在渊  → 试探，可能跃升
5/9: 九五 · 飞龙在天  → 大成，最佳状态
6/9: 上九 · 亢龙有悔  → 过极，需要收敛
7-9/9: 用九 · 群龙无首 → 归元，完成循环
```

### **Slide 13: 技术亮点 — 主权验证**

**ZKP 零知识证明**:
```
用户 → ECHO入口 → 创作者沙箱（私域）
                        ↓
                 执行Skill逻辑（ECHO看不见）
                        ↓
                 生成ZKP证明
                        ↓
ECHO ← 验证ZKP（只验证证明，不看内容）
                        ↓
              链上结算 → 用户收到结果
```

**核心特性**:
- ✓ **主权**: 代码在创作者沙箱，ECHO 无法进入
- ✓ **可验证**: ZKP 证明执行确实发生
- ✓ **隐私**: Prompt、模型、过程完全保密
- ✓ **可组合**: Skills 可自由编排组合

**技术栈**:

| 组件 | 技术 | 作用 |
|------|------|------|
| 沙箱 | gVisor/Firecracker | 隔离执行 |
| 证明 | zk-SNARKs/zk-STARKs | 零知识验证 |
| 结算 | 智能合约 | 自动分润 |
| 存储 | IPFS + Arweave | 永久保存 |

**视觉**: 数据流向图 + 锁链图标

## 设计建议

### 视觉风格
- **主色调**: 深空黑 + 电光蓝 + 暗金
- **字体**: 思源宋体（中文）+ Inter（英文）
- **动效**: 粒子流动、能量波纹、八卦旋转
- **图标**: 线性 + 微渐变，易经卦象为装饰元素

### 页面布局
- 每页不超过3个核心信息点
- 多用对比表格，少用大段文字
- 关键术语首次出现加注释
- 复杂流程用分步骤图解

### 演讲节奏
- 整体时长: 20-25分钟
- 核心章节(3-8): 12分钟
- 问答预留: 5分钟
