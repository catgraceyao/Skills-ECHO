# ECHO 系统模拟器

## 项目概述

ECHO System Simulator 是一个单页交互式可视化工具，用于模拟和演示 ECHO 协议的核心理念：创作者主权、四权配置（用/衍/扩/益）、资产生命周期管理、事件流驱动以及 64 卦势场（ShiGraph）演化。

本模拟器将数据模型、核心引擎、前端 UI 和场景脚本整合为一个独立的 HTML 文件，打开浏览器即可运行，无需任何服务器或外部依赖。

## 使用说明

### 快速开始

1. 双击 `echo-simulator-final.html` 用浏览器打开（推荐 Chrome / Edge / Firefox）

## 核心概念速查

### 四权（Four Rights）

| 权 | 英文名 | 含义 | 模拟中体现 |
|----|--------|------|-----------|
| **用** | Usage | 使用权：谁可以调用资产 | 使用次数计数、成本记录 |
| **衍** | Derivative | 衍生权：谁可以基于资产创建新资产 | 衍生链、谱系图 |
| **扩** | Expansion | 扩展权：资产可在哪些平台分发 | 部署目标平台列表 |
| **益** | Benefit | 收益权：收益如何分配 | 总收益、分配记录 |

### 事件类型

| 事件 | 触发条件 |
|------|---------|
| `AssetRegistered` | 资产登记到 ECHO 注册表 |
| `UsageOccurred` | 资产被用户调用 |
| `DeploymentEvent` | 资产部署到某平台 |
| `DerivativeCreated` | 基于某资产创建衍生资产 |
| `CitationEvent` | 资产被引用/溯源 |
| `ShiStateChanged` | 资产势位（卦象）发生变化 |
| `PolicyAdjusted` | 四权策略被调整 |
| `RevenueDistributed` | 收益完成分配 |

### ShiGraph / 64 卦

每个资产具有一个 `shi` 属性（0–63），对应《易经》64 卦中的一卦。势位随事件演化：

- **坤**（0）：初始、静止、孕育
- **复**（1）：一阳来复，开始活跃
- **临**（8）：逐渐壮大，面临新境
- **泰**（16）：通泰，上下交济
- **大壮**（48）：盛极，声势浩大
- **乾**（63）：极致、圆满、纯阳

### 数据流

```
UI 事件（场景加载 / 播放控制）
    ↓
模拟引擎（EchoSimulator）
    ↓
状态更新（资产属性 / 事件历史 / ShiMap）
    ↓
UI 重渲染（Canvas 节点 / 日志 / 统计）
```

## 场景说明

### 场景 1：基础生命周期

**目标**：展示单个资产从登记到使用到收益分配的完整流程。

**流程**：
1. 资产「文本摘要器」登记
2. 用户 Bob 调用 → 记录使用
3. 用户 Charlie 调用 → 记录使用
4. 使用频率触发势变：坤 → 复
5. 收益分配：0.02 ECHO → Alice

### 场景 2：衍生链式反应

**目标**：展示蓝图的衍生能力与链式收益分配。

**流程**：
1. 蓝图「电商蓝图」登记
2. 一代衍生：Dave 创建「服装店铺」
3. 二代衍生：Eve 基于「服装店铺」创建「童装专区」
4. 引用事件：追溯至原始蓝图
5. 收益分配：Eve 50% / Dave 30% / Mallory 20%

### 场景 3：多资产协作网络

**目标**：展示多个技能组合成代理的协作模式。

**流程**：
1. 4 个技能登记：语音识别、NLP解析、知识检索、文本生成
2. 组合为代理「智能客服」
3. 用户请求触发技能链调用
4. 收益按链式分配
5. 部署到生产环境

### 场景 4：势场演化

**目标**：展示资产势位（Shi）随事件演化的完整路径。

**流程**：
1. 坤卦初始登记
2. 密集使用 → 复卦
3. 衍生激活 → 临卦
4. 大规模部署 + 使用 → 泰卦
5. 收益积累 → 大壮卦
6. 万级使用里程碑 → 乾卦

## 技术细节

### 架构

- **数据模型**：`Asset` 类 + `EchoEvent` 类
- **核心引擎**：`EchoSimulator` 类，管理状态、执行场景脚本
- **渲染器**：`CanvasRenderer` 类，2D Canvas 绘制节点/连线/粒子
- **UI 控制器**：`UIController` 类，绑定 DOM 事件与状态同步
- **性能监控**：`PerformanceMonitor` 类，FPS / 帧时间 / 事件速率

### 场景脚本格式

```javascript
{
    id: 'scenario-id',
    name: '场景名称',
    desc: '场景描述',
    setup: (sim) => { /* 初始化资产 */ },
    script: [
        { delay: 500, action: 'emit', type: 'AssetRegistered', assetId: 'A1', data: {} },
        { delay: 1500, action: 'createDerived', parentId: 'A1', asset: { id: 'A2', ... } },
        { delay: 2500, action: 'emit', type: 'ShiStateChanged', assetId: 'A1', shiShift: 1 }
    ]
}
```

### 导出状态格式

```json
{
    "version": "1.0",
    "timestamp": 1715000000000,
    "simTime": 5200,
    "assets": [ /* Asset.toJSON() 数组 */ ],

    "stats": {
        "totalRevenue": 0.05,
        "usageCount": 3,
        "derivativeCount": 1,
        "platformCount": 2
    }
}
```
