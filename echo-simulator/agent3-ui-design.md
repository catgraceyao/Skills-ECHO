## 1. 设计概述

### 1.1 项目定位
ECHO 系统模拟器是一个用于可视化展示"使用权生命周期网络"概念的单页应用。目标用户是理解 ECHO 协议核心概念（四权、六档、验证图、势体系）的开发者、研究者和决策者。

### 1.2 设计原则
1. **信息密度优先** — 复杂系统的可视化需要同时呈现多维度信息
2. **分层揭示** — 概览→摘要→详情的渐进式信息架构
3. **即时反馈** — 所有交互操作在 100ms 内给出视觉反馈
4. **暗色护眼** — 长时间观察模拟运行的场景下保护视觉

## 3. 界面布局

### 3.1 整体结构 (Z 轴分层)

```
Z-30: 资产详情侧边栏 (overlay)
Z-20: 顶部仪表盘 + 底部控制台 (固定)
Z-10: 左侧边栏 (用户面板 + 事件日志)
Z-0:  网络图主区域 (自适应)
```

### 3.2 顶部仪表盘 (Header)
- **高度**: 56px
- **内容**:
  - 左侧: Logo + 系统名称 + 副标题
  - 中部: 4 个统计指标 (资产数 / 活跃用户数 / 验证事件数 / 生态总价值)
  - 右侧: "势图接管" 开关 (toggle switch)

### 3.3 主内容区 (Flex 布局)
- **左侧边栏**: 固定 224px 宽
  - 上: 参与者列表 (用户卡片 ×3)
  - 下: 事件日志流 (可滚动，最新在前)
- **中央区域**: 弹性填充
  - D3.js 力导向图 (全区域)
  - 悬浮工具: 重置视图、暂停物理
  - 悬浮图例: 生命阶段(左下) + 四权力(右上)
- **右侧边栏**: 绝对定位，380px，滑入滑出

### 3.4 底部控制台 (Footer)
- **高度**: 自适应 (~48px)
- **内容** (从左到右):
  1. 场景选择器: 4 个预设场景按钮
  2. 分隔线
  3. 操作按钮组: 创建资产 / 引用 / 改编 / 整合 / 分叉 / 支付 / 配置
  4. 弹性填充
  5. 时间轴控制: 播放/暂停 | 后退 | 滑块 | 前进 | 快进

## 4. 核心视图详解

### 4.1 验证图 (网络图)

**技术**: D3.js v7 Force Simulation

#### 节点设计
- **形状**: 圆形
- **大小**: 半径 = 12 + (势位分数 / 5)，范围 12-32px
- **填充**: 阶段色，透明度 20%
- **描边**: 阶段色，2px
- **内部图标**: 菱形/圆形符号表示阶段
- **活跃态**:
  - 外圈发光描边 (4px, 阶段色, 50%透明度)
  - CSS 脉冲动画 (2s ease-out infinite, scale 1→2.5, opacity 0.8→0)
- **标签**: 节点下方，11px，灰色，截断至 8 字符

#### 边设计
- **颜色**: `#2a4a6a` (深蓝灰)
- **粗细**: 1.5px
- **箭头**: SVG marker, 青色箭头
- **流动态**: `stroke-dasharray: 5,5` + CSS 动画 (1s linear infinite)

#### 交互
- **hover**: 显示浮动 tooltip (资产名、阶段、势位、所有者、状态)
- **click**: 打开右侧资产详情面板
- **drag**: 可拖拽节点，物理引擎实时响应
- **zoom**: 鼠标滚轮/捏合缩放，范围 0.3x-4x

### 4.2 资产详情面板 (右侧滑出)

**动画**: transform translateX, 300ms, cubic-bezier(0.4,0,0.2,1)

#### 内容模块

**① 势位仪表盘**
- SVG 半圆弧线 (180°)
- 背景弧: 深色
- 填充弧: 阶段色，stroke-dashoffset 动画过渡 (600ms)
- 中心: 大字号分数 + "/ 100"
- 阶段标签: 右上

**② 四权雷达图**
- SVG 四轴雷达图
- 网格: 5 层同心菱形
- 数据区域: 半透明填充 + 2px 描边 (青色)
- 数据点: 3px 圆点
- 轴标签: 用/扩/衍/益
- 底部: 四权当前档位文字网格

**③ 权限档位明细**
- 4 行卡片
- 每行: 图标(圆形底色) + 权力名 | 档位名 + 档位描述
- 档位描述: 禁/己/亲/约/法/公 → 对应文字说明

**④ 验证事件时间线**
- 竖向时间线
- 节点: 圆点 (青色，最新事件为金色)
- 连接线: 1px 竖线
- 内容: T+时间 + 事件描述

**⑤ 分润记录**
- 行列表: 来源用户 | 金额 (红色)
- 空态: "暂无分润记录"

**⑥ 规则模板**
- 纯文本块
- 自然语言描述许可条款

### 4.3 模拟控制台

#### 场景选择器
- 4 个按钮: 独立音乐人 / 开源软件 / 视觉艺术 / 多Agent经济
- active 态: 青色边框 + 半透明青色背景
- hover: 边框变青色

#### 操作按钮
- 创建资产: 主按钮样式 (青色背景透明版)
- 其他操作: 次级按钮 (深色背景 + 边框)
- 图标 + 文字

#### 时间轴
- 滑块: 自定义样式 (青色 thumb, 深色 track)
- 播放控制: 播放/暂停 + 步进 + 快进
- 时间显示: "T+{n}"

## 5. 动画与动效

### 5.1 入场动画
- 统计数字: 从 0 计数到目标值 (可选)
- 面板: 轻微上浮 + fade in
- 网络图: 节点从中心散开

### 5.2 交互动画
- 节点 hover: 无动画，即时 tooltip
- 节点 click: 侧边栏 300ms 滑入
- 时间轴播放: 每 500ms 推进一个 tick
- 势位仪表盘: 600ms stroke-dashoffset 过渡
- 雷达图: 数据区域绘制动画

### 5.3 背景效果
- 脉冲环: CSS keyframes, 2s, ease-out, infinite
- 流动边: CSS keyframes, 1s, linear, infinite, stroke-dashoffset
- CRT 扫描线: 静态 CSS overlay
- 网格背景: 静态 CSS background-image

## 6. 数据模型与映射

### 6.1 场景数据结构
```javascript
{
  name: string,           // 场景名称
  assets: Asset[],         // 资产数组 (≥5)
  users: User[],           // 用户数组 (≥3)
  events: Event[],         // 事件数组 (≥10)
  totalValue: number       // 生态总价值
}
```

### 6.2 Asset 结构
```javascript
{
  id: string,              // 唯一标识
  name: string,            // 显示名称
  owner: string,           // 用户 ID
  stage: 0-4,              // 生命阶段
  score: 0-100,            // 势位分数
  rights: {                // 四权档位
    use: 0-5,
    expand: 0-5,
    derive: 0-5,
    benefit: 0-5
  },
  active: boolean,         // 是否活跃 (影响脉冲动画)
  revenue: Revenue[],      // 分润记录
  rules: string,           // 规则模板文本
  created: number          // 创建时间 (tick)
}
```

### 6.3 事件类型映射到视觉
| 类型 | 图标 | 日志样式 |
|------|------|----------|
| create | fa-plus | success (绿色左线) |
| verify | fa-check | info (青色左线) |
| pay | fa-coins | info (青色左线) |
| cite | fa-quote-right | info (青色左线) |
| derive | fa-random | warn (黄色左线) |
| merge | fa-object-group | warn (黄色左线) |
| fork | fa-code-branch | warn (黄色左线) |
| stage_up | fa-arrow-up | success (绿色左线) |
| config | fa-sliders-h | info (青色左线) |

## 10. 交互状态矩阵

| 状态 | 视觉表现 | 触发条件 |
|------|----------|----------|
| 默认 | 静态展示 | 页面加载完成 |

| 暂停 | 播放按钮变播放图标 | 点击暂停 |
| 势图接管开启 | Toggle 变青色 | 用户开启 |
| 场景切换 | 数据刷新 + 图重建 | 点击场景按钮 |

## 11. 已知限制与后续优化

1. **移动端**: 当前未完全优化移动端交互
2. **性能**: 大量节点 (>100) 时力导向模拟可能需要 Web Worker
3. **实时数据**: 当前为静态模拟数据，可接入真实 API
4. **3D 视图**: 可考虑 Three.js 实现 3D 网络图
5. **导出**: 可添加 PNG/SVG 导出功能
6. **历史回放**: 时间轴可扩展为完整历史 scrubber
