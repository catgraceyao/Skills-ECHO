## 一、ECHO核心设计逻辑提炼

### 1.1 核心哲学

ECHO是**使用权生命周期网络**，不是所有权协议。
- 记录资产的生长全周期：被谁使用、怎么用、谁验证
- 核心解决**使用权**，不是所有权
- "登记"替代"铸造"，"流转"替代"转移"
- 使用痕迹本身成为价值来源

### 1.2 四权×六档（创作者语义表达系统）

| 四权 | 含义 | 档位（位掩码可组合） |
|------|------|-------------------|
| **用** | 谁能接触内容 | 禁(0)·己(1)·亲(2)·约(3)·法(4)·公(5) |
| **扩** | 内容可传播到哪里 | 禁(0)·己(1)·亲(2)·约(3)·法(4)·公(5) |
| **衍** | 内容可被怎样改造 | 禁(0)·己(1)·亲(2)·约(3)·法(4)·公(5) |
| **益** | 收益如何分配 | 禁(0)·己(1)·亲(2)·约(3)·法(4)·公(5) |

六档的经济关系递进：
```
己(私有) → 亲(礼物经济) → 约(市场经济) → 法(社区自治) → 公(公共品)
```

档位组合的传递性：AB可 + BC可 → ABC也可。结果=各档位权限的并集。
禁止组合：{0,任何}、{5,1/2}、{0,3/4}。

### 1.3 验证图（关系网络）

```
G = (V, E, W)
V = {资产节点}
E = {验证事件边} — reference(引用)/remix(改编)/integrate(整合)/fork(分叉)
W = {边权重} — 语义深度 × 时间衰减
```

### 1.4 势体系（生态免疫系统）

**三层架构**：
1. **势枢(ShiShu)** — 验证图拓扑（节点=资产，边=验证事件）
2. **势场(ShiChang)** — 生态协议约束（只开放，不收紧；保护既有关系）
3. **势位(ShiWei)** — 5生命阶段

**势位公式**：P = 0.4×时间密度T + 0.4×中心性S + 0.2×语义跨越C

**5生命阶段**：
- **潜藏** (P<20)：无验证事件，独立存在 → 无约束
- **显现** (P<40)：开始被引用 → 建议开放
- **生长** (P<60)：中度连接 → 自动开放（每次最多升1档）
- **大成** (P<80)：高度连接 → 锁定最低档，禁止收紧
- **转化** (P≥80)：周期尾声 → 建议完全开放或冻结

**势图接管**：可选机制，根据全网态势自动调整档位。
- 核心规则：只开放，不收紧（新配置=旧配置 OR 建议配置）
- 创作者可随时关闭接管

### 1.5 六条元规则

1. **初始配置不可篡改** — 谁有权利
2. **配置即承诺** — 权利如何使用
3. **流动即执行** — 承诺如何生效
4. **衍生即继承** — 承诺如何传递
5. **版本即历史** — 承诺如何保护
6. **势位即边界** — 承诺如何适应变化

### 1.6 规则市场

- 规则模板由用户创建/共享/交易
- 嵌入约档(3)和法档(4)
- 付费即规则：付费是嵌入约档的可选约束条件

### 1.7 分润体系

- 多级递归分配（引用链上溯）
- 每层衰减系数0.5
- 事件类型决定分润比例：purchase/remix/view

## 二、东方美学视觉规范

### 2.1 设计理念

**"万物有灵，皆可生长"**

ECHO是生态，不是机器。东方美学的核心是"气韵生动"——不是僵硬的UI组件，而是有呼吸、有生长感的界面。

### 2.2 色彩系统

**主色调（墨色系列）**：
```
墨黑    #0c0c0e  — 最深背景
玄灰    #1a1a1e  — 面板背景
烟灰    #2a2a30  — 边框、分隔线
雾灰    #8a8a90  — 次要文字
素白    #f0f0e8  — 主要文字
```

**点缀色（东方矿物色）**：
```
朱砂    #c45c48  — 警示、禁止、重要操作
石青    #4a90a4  — 信息、用权、连接
石绿    #5a9a6e  — 生长、成功、衍生
藤黄    #c8a84c  — 大成、势位、收益
赭石    #8b6914  — 传统、历史、版本
黛蓝    #2c3e50  — 深邃、法权、社区
```

**生命阶段配色**：
- 潜藏：墨色渐变（#0c0c0e → #2a2a30）
- 显现：石青色晕染
- 生长：石绿色渐变
- 大成：藤黄色光华
- 转化：朱砂+墨色交织

### 2.3 纹理与质感

- **宣纸纹理**：背景叠加 subtle paper grain
- **水墨边界**：面板边缘有晕染效果（CSS mask + gradient）
- **云雾流动**：动画背景用CSS或Canvas绘制飘动的云雾
- **墨点扩散**：交互反馈用墨点扩散动画

### 2.4 字体

- **标题**：书法体 — 华文行楷 / 方正清刻本悦宋 / 或系统自带的 serif
- **正文**：清晰无衬线 — Noto Sans SC / 思源黑体
- **数据/代码**：等宽 — JetBrains Mono

### 2.5 元素造型

- **按钮**：圆角矩形 + 水墨 hover 效果（墨迹从中心扩散）
- **卡片**：不规则边缘（模拟宣纸裁剪）+ 阴影如山水画层次
- **图标**：简化东方符号（太极简化、云纹、山水轮廓）
- **图表**：水墨风格（雷达图用墨迹晕染、柱状图用山峰轮廓）

### 2.6 动画语言

- **缓动函数**：ease-in-out-cubic（如毛笔起落）
- **粒子系统**：墨点飘散、花瓣飘落、云雾流动
- **生长动画**：元素如植物生长般展开（stroke-dashoffset绘制）
- **过渡**：页面切换如卷轴展开

## 三、页面架构（6页面SPA）

### 页面0：首页 — ECHO宇宙观

**定位**：概念入口，东方美学第一印象

**内容**：
- 全屏水墨粒子动画背景（墨色粒子如星云般缓慢旋转）
- 中央：ECHO 书法大字 + 副标题"使用权生命周期网络"
- 底部：五行概念导航（用罗盘、扩山水、衍生长、益流金、势天地）
- 简短哲学引言："万物有灵，皆可生长。势体系让生长有方向，让开放有边界。"

**视觉**：最仙气的页面，云雾缭绕，粒子如墨滴在水中扩散

---

### 页面1：四权六档 — 罗盘配置器

**定位**：核心配置逻辑的可视化

**内容**：
- **中央**：大型罗盘/玉璧可视化（四个同心圆环=四权）
  - 外环=用（石青色）
  - 次环=扩（藤黄色）  
  - 三环=衍（石绿色）
  - 内环=益（朱砂色）
- **六档刻度**：每环分为6档（禁·己·亲·约·法·公），用墨色渐变表示
- **交互**：点击某环的某档位，该档位"点亮"（水墨晕染效果）
  - 多选=档位组合（位掩码）
  - 实时显示当前配置的JSON
- **验证**：禁止组合用红色水墨晕染提示错误
- **规则市场**：右侧卷轴展开模板列表
- **预览区**：底部显示"如果用此配置，某用户做某操作会怎样"

**视觉**：罗盘如古代天文仪器，精密而神秘

---

### 页面2：验证图 — 水墨关系网络

**定位**：资产关系网络的可视化

**内容**：
- **主视图**：水墨风格D3力导向图
  - 节点=资产，形状=简化印章（圆角矩形）
  - 节点颜色=生命阶段（墨色→石青→石绿→藤黄→朱砂）
  - 节点大小=势位分数
  - 边=验证事件，样式=水墨笔触（细线为引用，粗线为改编）
  - 边动画=墨迹流动效果
- **交互**：
  - 拖拽节点
  - 点击节点 → 右侧展开资产详情（卷轴式面板）
  - 滚轮缩放
  - 双击节点 → 展开/折叠子网络
- **时间轴**：底部可拖动，查看历史时刻的网络状态
- **筛选器**：按验证事件类型/生命阶段/时间范围筛选

**视觉**：如一幅会动的山水画，资产是山，验证事件是河流

---

### 页面3：势体系 — 山水演化

**定位**：生命阶段+势图接管的完整展示

**内容**：
- **主视图**：纵向山水长卷（从上到下=潜藏→转化）
  - 底部=土壤/种子（潜藏，墨色）
  - 下部=嫩芽破土（显现，石青色）
  - 中部=枝叶伸展（生长，石绿色）
  - 上部=大树成荫（大成，藤黄色）
  - 顶部=落叶归根（转化，朱砂+墨色）
- **势位仪表盘**：左侧显示当前选中资产的
  - 势位分数（0-100水墨进度条）
  - 三维指标（时间密度T/中心性S/语义跨越C）水墨柱状图
  - 生命阶段标签
- **势图接管面板**：右侧显示
  - 是否启用
  - 当前阶段约束
  - 建议/已应用的配置变更
  - "只开放，不收紧"的原则提示
- **验证事件流**：底部时间线显示影响势位的事件

**视觉**：如《千里江山图》的数字版，山水即数据

---

### 页面4：场景模拟 — 多Agent社会经济

**定位**：完整场景的自动/手动模拟

**内容**：
- **场景选择器**：左侧卷轴列表
  - 场景1：独立音乐人生态生长
  - 场景2：开源软件社区自治
  - 场景3：多Agent社会经济活动
  - 场景4：势图接管冲突与解决
- **主视图**：分屏显示
  - 上半=验证图网络（实时演化）
  - 下半=经济活动面板（交易记录、余额变化、分润明细）
- **Agent面板**：右侧显示各个Agent的状态
  - 头像、角色、余额、声誉、当前行为
  - 用不同颜色区分（创作者=石青，使用者=石绿，平台=藤黄）
- **控制栏**：播放/暂停/步进/重置/速度调节
- **事件日志**：实时滚动，水墨风格日志项

**视觉**：如古代市井画卷，Agent如人物在市集中活动

---

### 页面5：规则市场 — 东方市集

**定位**：规则模板的交易与展示

**内容**：
- **市集布局**：网格卡片，如古代店铺招牌
  - 每个模板=一个"店铺"卡片
  - 招牌=模板名称（书法体）
  - 门口=四权配置预览（简化罗盘）
  - 价格=银两/铜钱图标
  - 人气=使用次数（如"已有523位来客"）
- **筛选**：领域（音乐/视频/代码/文字）× 开放度 × 价格
- **详情弹窗**：卷轴展开式
  - 完整四权雷达图
  - 分润规则
  - 版本历史
  - 用户评价
- **创建模板**："开新店"流程

**视觉**：如清明上河图的局部，热闹而有秩序

## 四、技术架构

### 4.1 整体结构

```
index.html          # 入口，路由+公共样式+导航
├── pages/
│   ├── home.html       # 首页
│   ├── rights.html     # 四权六档罗盘
│   ├── graph.html      # 验证图网络
│   ├── shi.html        # 势体系山水
│   ├── simulate.html   # 场景模拟
│   └── market.html     # 规则市集
├── css/
│   ├── base.css        # 东方美学基础样式（色彩/字体/纹理）
│   ├── animations.css  # 水墨动画（粒子/云雾/墨点）
│   └── components.css  # 公共组件（卷轴/罗盘/印章）
├── js/
│   ├── engine.js       # 核心引擎（Permission/Revenue/Shi/Graph/Takeover）
│   ├── data.js         # 模拟数据（场景预设）
│   ├── router.js       # 页面路由
│   └── utils.js        # 工具函数
└── assets/
    └── textures/       # 宣纸纹理等静态资源
```

### 4.2 核心引擎模块

1. **PermissionEngine** — 四权验证
2. **RevenueEngine** — 分润计算  
3. **ShiEngine** — 势位计算
4. **GraphEngine** — 验证图管理
5. **ShiTakeoverEngine** — 势图接管
6. **RuleMarketEngine** — 规则市场

### 4.3 技术栈

- **HTML5** — 语义化结构
- **CSS3** — Grid/Flex布局、CSS动画、CSS变量
- **Vanilla JS** — ES6+，无框架依赖
- **D3.js v7** — 验证图网络可视化
- **Canvas 2D** — 粒子系统、水墨特效
- **SVG** — 图标、罗盘、印章元素

## 五、交互设计要点

### 5.1 全局交互

- **导航**：左侧固定竖导航（如竹简卷轴），当前页面高亮
- **页面切换**：卷轴展开动画（CSS transform + opacity）
- **提示**：水墨风格toast（从底部墨迹晕染出现）
- **加载**：墨点旋转loading

### 5.2 各页面交互

**罗盘配置器（页面1）**：
- 鼠标悬停某档位 → 显示tooltip解释（如"约档：契约边界，市场交易"）
- 点击选择 → 墨点扩散确认动画
- 配置完成 → 预览区实时更新

**验证图（页面2）**：
- 节点悬停 → 显示资产卡片（印章式tooltip）
- 节点点击 → 右侧卷轴面板滑出
- 边悬停 → 显示验证事件详情

**势体系（页面3）**：
- 点击某资产 → 山水长卷中该资产高亮
- 时间轴拖动 → 山水渐变（如季节变化）

**场景模拟（页面4）**：
- 播放时 → 节点脉动、边流动、Agent头像移动
- 暂停时 → 可手动操作任何Agent
