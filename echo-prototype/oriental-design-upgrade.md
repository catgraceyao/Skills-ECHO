# ECHO 东方美学设计升级方案

## 核心问题诊断

| 问题 | 现状 | 目标 |
|------|------|------|
| 留白 | 元素密集，边距统一16-24px | 大量呼吸空间，边距40-80px |
| 墨色 | 纯黑文字#1a1a1a | 墨色层次 #333 → #666 → #999 |
| 质感 | 扁平现代 | 宣纸肌理、水墨晕染 |
| 动线 | 信息并列堆砌 | 纵向流动，一步一景 |
| 字体 | 单一字体大小 | 字号对比强烈，大量留白配小字 |

---

## 东方美学五诀

### 一、留白 · 虚实相生

```
传统：计白当黑，无画处皆成妙境
设计：空白不是缺失，而是呼吸与等待

实施：
- 页面边距：桌面端80px，移动端32px
- 模块间距：最小64px
- 卡片内边距：32px（甚至48px）
- 一行不超过15个中文字
```

### 二、墨色 · 浓淡干湿

```css
/* 墨色层次 */
--ink-heavy: #0d0d0d;    /* 浓墨 - 主标题 */
--ink-medium: #404040;   /* 中墨 - 正文 */
--ink-light: #737373;    /* 淡墨 - 辅助文字 */
--ink-faint: #a6a6a6;    /* 清墨 - 装饰/禁用 */
--ink-trace: #d9d9d9;    /* 飞白 - 分隔线 */
```

### 三、竖排 · 气韵生动

```
关键标题采用竖排或竖排思维：
- 单行文字竖排
- 段落保持横排但行高极大
- 标题与正文形成「竖向张力」
```

### 四、印章 · 点睛之笔

```
朱砂红 sparingly used：
- 不超过页面面积的2%
- 只用于：主按钮、当前状态、印章标记
- 大面积留白中的一点红
```

### 五、卷轴 · 徐徐展开

```
内容呈现像画卷缓缓打开：
- 渐进式加载
- 滚动触发动画
- 没有突兀的跳转
```

## 页面重构要点

### 首页重构

**Before:**
- 导航 + Hero + 三模块卡片 + 功能介绍 + 资产展示
- 每个区块信息密度高
- 边距16-24px

**After:**
- 全屏 Hero（80%留白）
- 单模块全屏展示（一次只看一个模块）
- 边距80px+
- 墨色书法大字 + 极小英文注解

### 编辑器重构

**Before:**
- 三栏布局，工具栏密集
- 功能按钮平铺
- 色彩丰富

**After:**
- 单栏或双栏极简
- 工具隐藏，手势/快捷键操作
- 近乎单色的界面，内容本身即色彩
- 宣纸纹理背景

- **原研哉** - 白、空、自然肌理

### 排版参考
- **日本杂志《花椿》** - 竖排标题+横排正文
- **台湾《诚品好读》** - 呼吸感排版
- **电影《刺客聂隐娘》** - 空镜头美学

### 交互参考

## 实施优先级

1. **P0 - 首页重构** - 第一印象，必须惊艳
2. **P1 - 全局样式** - 字体、色彩、间距系统
3. **P2 - 编辑器简化** - 音/画/文三模块
4. **P3 - 动效优化** - 卷轴展开感、墨色晕染
