# ECHO 势体系配套应用设计 v1.0

> **设计理念**: 势是描述框架，不是控制系统。配套应用帮助创作者理解、观测、参与资产的生长过程。
> **核心原则**: 我们不是设计者，是观测者。应用不控制，只呈现。

##### 1.2.3 约束解释与教育

**坤卦约束解释**:
```
为什么坤卦（潜藏期）限制衍权？

🌱 类比：种子在地下发芽

此时资产还未被充分使用，生态依赖关系尚未形成。
如果此时开放高衍生，可能导致：
• 衍生作品质量不可控（原作品未经验证）
• 创作者无法有效维护衍生生态
• 用户难以判断原作品价值

建议：专注打磨核心功能，积累使用记录。
当进入屯卦（萌芽期），衍权限制将自动放宽。

📊 数据支持：过往坤卦资产高衍生的失败率 73%
```

```typescript
// ShiGraph SDK 核心接口

interface ShiGraphClient {
  // 查询资产势位
  getPosition(assetId: string): Promise<ShiPosition>;
  
  // 查询三维坐标
  getCoordinate(assetId: string): Promise<ShiCoordinate>;
  
  // 订阅势位变化
  subscribePositionChanges(
    assetId: string, 
    callback: (change: PositionChange) => void
  ): Subscription;
  
  // 查询当前卦象约束
  getConstraints(hexagram: Hexagram): Promise<HexagramConstraints>;
  
  // 计算有效配置
  calculateEffectivePolicy(
    blueprint: Blueprint,
    position: ShiPosition
  ): Promise<EffectivePolicy>;
}

interface ShiPosition {
  assetId: string;
  hexagram: Hexagram;           // 当前卦象
  stage: LifeStage;             // 生命阶段
  coordinate: ShiCoordinate;    // 三维坐标 [时间, 空间, 关系]
  yao: SixYao;                  // 六爻坐标
  energy: number;               // 势能（气数）
  updatedAt: Timestamp;
}

interface ShiCoordinate {
  temporal: 0 | 1 | 2 | 3;      // 时间维度
  spatial: 0 | 1 | 2 | 3;       // 空间维度
  relational: 0 | 1 | 2 | 3;    // 关系维度
}
```

## 第五部分：数据模型设计

### 1. 核心实体

```typescript
// 资产 (Asset)
interface Asset {
  id: string;                    // 唯一标识
  name: string;                  // 名称
  creator: string;               // 创作者地址
  createdAt: Timestamp;
  
  // 当前势位（缓存，可从事件流重建）
  currentPosition: ShiPosition;
  
  // 当前有效配置（与物理法则交集后的结果）
  effectivePolicy: EffectivePolicy;
}

// 四权蓝图 (Blueprint)
interface Blueprint {
  assetId: string;
  version: string;               // 版本号
  createdAt: Timestamp;
  
  // 创作者意图
  yong: UsagePolicy;             // 用权
  yan: DerivativePolicy;         // 衍权
  kuo: ExpansionPolicy;          // 扩权
  yi: BenefitPolicy;             // 益权
  
  // 版本管理
  previousVersion?: string;
  isActive: boolean;             // 是否接受新授权
}

// 势位 (ShiPosition)
interface ShiPosition {
  assetId: string;
  hexagram: Hexagram;            // 64卦之一
  coordinate: ShiCoordinate;     // 三维坐标
  yao: SixYao;                   // 六爻坐标
  energy: number;                // 势能
  updatedAt: Timestamp;
}

// 事件 (Event) - 真相来源
interface Event {
  id: string;
  type: EventType;               // UsageOccurred, ShiChanged, etc.
  assetId: string;
  timestamp: Timestamp;
  data: EventData;               // 事件特定数据
  signatures: Signatures;        // 签名链
}
```

### 2. 存储架构

```
Kafka 事件流 (热数据，最近90天)
    ↓
PostgreSQL 事件持久化 (温数据，全量)
    ↓
IPFS 归档 (冷数据，历史)

Redis 状态缓存 (可重建)
    • 资产当前势位
    • 有效配置缓存
    • 使用计数统计
```
