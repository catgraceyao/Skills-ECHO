## 1. 文档说明

### 1.1 背景

ECHO 模拟器 v0.1 的原设计将六个模块（仪表盘、资源浏览器、资源详情、用户浏览器/详情、推演播放器、规则配置）平铺在同一层级，存在以下问题：
- 用户进入后不知道**先做哪个**
- 仪表盘作为默认着陆页，但空状态无意义
- 推演播放器找不到入口
- 资源/用户模块与主线模块混淆

### 1.2 设计原则

**核心原则：时间主线优先，观察维度穿透**

- 时间主线（三层）构成**用户旅程**：配置 → 运行 → 复盘
- 观察维度（两层）作为**全局下钻能力**：在任何时间点都可切入资源或用户视角
- 减少用户认知负荷，不让用户面对六个平铺选项做选择

### 1.3 视觉锚点

延续雅怡定义的宋代美学：
- 主背景：宣纸白 `#F5F0E6`
- 主强调：天水碧 `#5AA4AE`
- 辅助：朱砂 `#C85A54`（告警/异常）
- 文字：墨 `#2D3436`
- 留白克制，信息密度适中——模拟器是实验室，不是仪表盘

## 4. 第一层：时间主线

### 4.1 模块 1：规则配置面板（Rule Configurator）

#### 4.1.1 定位

用户进入模拟器的**默认着陆页**。所有实验从这里开始。类比：实验室的实验台。

#### 4.1.2 布局

- **中央**：分步向导 + 画布混合模式
- **左侧**：步骤导航（5步，可点击跳转）
- **右侧**：当前步骤的参数配置面板

#### 4.1.3 分步向导（5步）

| 步骤 | 标题 | 中央画布 | 右侧参数面板 |
|------|------|---------|------------|
| Step 1 | 基础设置 | 实验模板卡片网格（3×2） | 实验名称、时长、步长、随机种子 |
| Step 2 | Agent 部署 | 力导向图画布（节点=Agent，边=关系） | Agent类型选择器、批量生成、属性分布 |
| Step 3 | Skill 市场 | Skill分类卡片树 | 分类体系、初始供给、品质分布、定价策略 |
| Step 4 | Echo 规则 | 拓扑高亮预览（规则修改影响区域实时着色） | 确权参数、收益分配、治理阈值、冷却期 |
| Step 5 | 预览确认 | 实验配置摘要拓扑图 | 参数校验、冲突检测、影响预估、保存/启动 |

#### 4.1.4 关键交互

**Step 2 — Agent 画布**
- 拖拽放置Agent节点到画布
- 节点类型用形状区分：创作者（△）、消费者（○）、中介（◇）、治理（□）
- 连线表示关系：社交关系（实线）、合作关系（虚线）、信任关系（双线）
- 拖拽时力导向图实时重排
- 右键节点 → 删除 / 复制 / 属性编辑

**Step 3 — Skill 关联**
- 从 Skill 卡片拖拽到 Agent 节点 → 绑定创建者
- 创建者绑定后，该 Skill 的卡片边框显示该 Agent 的颜色标记
- 支持批量：选中多个 Skill → 右键「绑定到选中Agent」

**Step 4 — 规则影响预览**
- 调整收益分配比例时，画布上的创作者节点亮度实时变化（比例越高越亮）
- 调整冷却期时，高连接度节点闪烁预警（这些节点受冷却期影响最大）
- 参数校验：冲突项标红（如收益分配总和 > 100%）

**Step 5 — 启动模拟**
- 点击「启动模拟」→ 验证通过 → 自动跳转到推演播放器
- 点击「保存草稿」→ 进入实验管理列表
- 点击「另存为模板」→ 弹出模板名称输入，保存到模板库

#### 4.1.5 与观察维度的联动

- Step 2 点击 Agent 节点 → 右侧属性面板切换为**用户详情**（预览版，显示预估行为）
- Step 3 点击 Skill 卡片 → 右侧属性面板切换为**资源详情**（预览版，显示预估衍生链）
- 预览版数据为模拟前估算，非真实运行数据

#### 4.1.6 数据需求

```typescript

  id: string;
  name: string;
  templateId?: string;        // 继承的模板
```

### 4.2 模块 2：推演播放器（Simulation Player）

#### 4.2.1 定位

核心体验模块。模拟运行时的**动态回放与观察**。类比：时光机。

#### 4.2.2 布局

- **顶部**：播放控制栏（始终可见）
- **中央**：主视角渲染区（占据60%面积）
- **左侧**：事件列表 + 时间轴（可折叠）
- **右侧**：实时参数面板（可折叠）

#### 4.2.3 播放控制栏

```
[⏮ 重置] [⏴ 步退] [▶ 播放 / ⏸ 暂停] [⏵ 步进] [⏩ 加速 ▾] [📍 注入事件]
[时间轴滑块：T=0 ———●—————————————————— T=200]
[当前步: 47/200] [活跃Agent: 23] [待处理交易: 7] [网络延迟: 12ms]

加速下拉：x0.5 / x1 / x2 / x5 / x10 / MAX
```

**控制说明**：
- 重置：回到 T=0，清空所有运行时状态
- 步退/步进：单步前进/后退，步进时显示「步进模式」徽章
- 播放/暂停：正常播放，暂停时所有数据冻结
- 加速：x0.5 为慢动作（适合观察细节），MAX 为最快（适合快速推进）
- 注入事件：弹出事件选择器（预设冲击事件或自定义参数）

**时间轴滑块**：
- 滑块上有刻度标记：降档（红●）、分叉（橙●）、新节点（绿●）、治理提案（蓝●）
- 悬停刻度 → 显示事件摘要 tooltip
- 点击刻度 → 自动跳转到该时间步并暂停

#### 4.2.4 三种视角（核心设计）

| 视角 | 快捷键 | 渲染内容 | 适合观察 | 下钻能力 |
|------|--------|---------|---------|---------|
| **宏观网络** | 1 | 全量Agent节点 + Skill流转边。节点大小=势位，颜色=类型，边粗细=交易量 | 生态结构、中心节点、桥接边 | 点击节点 → 用户详情 |
| **中观领域** | 2 | 按Skill分类分组柱状图。每组显示创作者/消费者/交易量 | 市场结构、供需平衡、领域热度 | 点击柱子 → 资源浏览器（该领域） |
| **微观个体** | 3 | 单个Agent第一人称视角。Skill持有、交易历史、决策逻辑、势位变化 | 个体行为、决策链、势位崩塌 | 本身就是用户详情 |

**宏观网络图细节**：
- 力导向布局，节点质量与势位成正比
- 创作者（△）蓝色系、消费者（○）绿色系、中介（◇）橙色系、治理（□）灰色系
- 边的粗细与累计交易量成正比
- 边的颜色渐变：冷色（低频）→ 暖色（高频）
- 高势位节点有光晕效果（可开关）
- 支持框选多个节点 → 显示群体统计

**中观领域图细节**：
- X轴：Skill分类（NLP/代码/分析/...）
- Y轴：数量/金额（可切换）
- 每个分类下分三组：创作者数量、消费者数量、交易量
- 柱状图顶部显示该分类的桥接密度 ρ 值
- 点击柱子 → 右侧展开该分类的**资源浏览器**
- 支持堆叠/分组/百分比三种模式切换

**微观个体追踪细节**：
- 顶部：Agent头像、名称、类型、当前势位、信誉分
- 左侧：时间轴（该Agent的关键事件）
- 中央：当前持有的Skill列表（卡片式，可点击展开）
- 右侧：决策日志（最近10条，每条显示决策理由摘要）
- 底部：关联网络（上下游3层，可点击跳转）
- 支持「锁定跟随」：播放时始终聚焦该Agent

#### 4.2.5 事件高亮系统

- 事件发生时，中央画布**自动闪烁**对应区域（1秒后恢复）
- 降档事件：红色脉冲扩散，中心节点抖动
- 分叉事件：橙色光束从原节点射向新节点
- 新节点加入：绿色涟漪扩散
- 治理提案：蓝色光柱从提案节点升起
- 用户可在事件列表中**回看**历史事件（点击后跳转到该时间步）

#### 4.2.6 多方案对比（A/B测试）

- 顶部勾选「对比模式」→ 弹出实验选择器（选择两个已保存实验）
- 中央画布**左右分屏**：左=A方案，右=B方案
- 播放时同步推进，使用同一随机种子
- 差异点自动闪烁高亮（如某节点在A中势位高、在B中势位低）
- 底部显示差异指标：Gini差、马太差、Shannon差、桥接密度差
- 支持「差异追踪」：选中某个节点，显示其势位在两方案中的差异曲线

#### 4.2.7 与观察维度的联动

- 宏观网络点击节点 → 右侧滑出**用户详情**（实时数据，动机-决策-行为链条）
- 中观领域点击柱子 → 右侧滑出**资源浏览器**（该领域全部Skill，实时状态）
- 微观视角本身就是用户详情，可通过「关联网络」→ 点击Skill → 右侧滑出**资源详情**
- 所有下钻操作不暂停播放，支持「边看模拟边看详情」

### 4.3 模块 3：系统仪表盘（System Dashboard）

#### 4.3.1 定位

实验结束后的**复盘与诊断**。类比：全局看板。

#### 4.3.2 布局

- **中央**：指标卡片 + 趋势图 + 归因分析
- **左侧**：实验列表/历史对比（可展开）
- **右侧**：自动报告 + 洞察建议（可展开）

#### 4.3.3 核心指标卡（6张）

```
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│  Skill流通总量  │  │  活跃Agent数   │  │  市场交易量     │
│   1,247      │  │     23       │  │   ￥892K     │
│   ↑12%       │  │   →持平      │  │   ↑34%       │
└──────────────┘  └──────────────┘  └──────────────┘
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│   Gini系数   │  │   马太系数    │  │   生态健康度   │
│   0.24       │  │    0.16      │  │   87/100     │
│   ↓0.03      │  │   ↓0.05      │  │   ↑5分       │
└──────────────┘  └──────────────┘  └──────────────┘
```

- 卡片颜色编码：健康（绿）、警告（黄）、危险（红）
- 趋势箭头：对比初始值 / 对比上一实验
- 点击卡片 → 展开详细趋势图（全屏弹窗）

#### 4.3.4 趋势分析

- 时间序列图：Gini、马太、Shannon、ρ、平均势位、交易量
- 支持**多曲线叠加**：选择多个实验对比（最多5条）
- **趋势分解**：
  - 长期趋势（平滑曲线）
  - 周期性波动（季节性分解）
  - 事件冲击（在曲线上标注事件点）
- 支持缩放：框选时间范围 → 放大查看细节

#### 4.3.5 归因分析

- **敏感性分析**：调整每个参数对Gini的影响程度（龙卷风图）
- **Shapley值**：各因素对生态健康度的贡献度（饼图）
- **关键发现自动标注**：
  - "β 从 0.01 调至 0.1 使 Gini 上升 0.08，但牺牲多样性"
  - "冷却期 C=7 对抑制恶意降档效果最佳，但过度抑制新节点"
  - "桥接密度 ρ=50% 时生态健康度最高，ρ=80% 时Gini过低但创新停滞"

#### 4.3.6 自动报告

- 一键生成结构化报告（包含上述所有图表和发现）
- 报告结构：
  1. 实验摘要（名称、参数、运行时长）
  2. 关键发现（3-5条，带图表）
  3. 参数建议（基于敏感性分析）
  4. 可视化附录（全部图表）
- 导出格式：PDF、飞书文档、Markdown
- 支持自定义模板（研究员可保存自己的报告模板）

#### 4.3.7 与观察维度的联动

- 点击 Gini 曲线异常点 → 下钻到该时间步的**资源浏览器**（查看当时市场结构）
- 点击某个 Agent 的势位变化 → 下钻到**用户详情**（查看完整行为链条）
- 点击关键发现中的 Skill 名称 → 下钻到**资源详情**（查看衍生树）

## 5. 第二层：观察维度

### 5.1 模块 4 & 5：资源浏览器 + 资源详情页

#### 5.1.1 资源浏览器（Resource Browser）

**定位**：全局可访问的**市场橱窗**。穿透任意时间点的辅助视角。

**入口**：
- 顶部全局栏「资源浏览器」按钮（始终可见）
- 推演播放器中观领域视角点击柱子
- 仪表盘点击关键发现中的 Skill 名称

**布局**：
- 左侧：筛选面板（分类、势位区间、创作者、时间范围）
- 中央：结果区（三种视图切换）
- 右侧：选中项预览（可展开为详情）

**三种视图**：

| 视图 | 描述 | 适用场景 |
|------|------|---------|
| 网格视图 | 卡片网格，每张卡片显示Skill名称、势位、价格、创作者头像 | 浏览发现 |
| 列表视图 | 表格，列：名称、分类、势位、价格、创作者、创建时间、交易量 | 对比筛选 |
| 图谱视图 | 力导向图，节点=Skill，边=衍生关系 | 观察衍生网络 |

**筛选器**：
- 分类：NLP / 代码 / 分析 / 视觉 / 音频 / 其他（多选）
- 势位区间：滑块 0-100
- 创作者：搜索选择（下拉列表）
- 时间范围：相对（最近1轮/10轮/50轮）或绝对（起止时间步）
- 品质：低/中/高（多选）
- 状态：活跃/已降档/已分叉（多选）

**排序**：热度、价格、势位、品质、创建时间、交易量（升降序）

#### 5.1.2 资源详情页（Resource Detail）

**定位**：单资源的**全生命周期档案**。

**布局**：
- 顶部：Skill 基本信息（名称、分类、创作者、创建时间、当前势位、当前价格）
- 左侧：生命周期时间轴（垂直）
- 中央：衍生树（核心可视化）
- 右侧：交易历史 + 收益记录
- 底部：关联推荐

**生命周期时间轴**：
```
● 创建 (T=0) ──● 首次交易 (T=12) ──● 首次衍生 (T=34) ──● 扩展 (T=56) ──● 当前 (T=200)
     │               │                   │                  │               │
  势位=0.1      势位=0.35            势位=0.52          势位=0.68       势位=0.71
```
- 点击时间轴节点 → 右侧显示该时间步的详细状态
- 时间轴上标注关键事件（交易、衍生、降档、分叉）

**衍生树（核心）**：
- 树状布局，根节点=当前Skill
- 子节点=直接衍生作品
- 孙节点=二次衍生
- 节点大小=该衍生作品的势位
- 节点颜色=创作者类型
- 点击节点 → 跳转到该衍生作品的详情页（新标签页）
- 支持展开/折叠层级
- 显示每个节点的「衍生贡献度」（即原始Skill对其势位的贡献比例）

**交易历史**：
- 表格：时间步、买方、卖方、价格、数量
- 支持导出CSV
- 点击买方/卖方 → 跳转到**用户详情**

**收益记录**：
- 表格：时间步、收益类型（直接交易/衍生分成/扩展授权）、金额、来源
- 累计收益曲线图
- 点击来源 → 跳转到对应**资源详情**或**用户详情**

**关联推荐**：
- 同类Skill（相同分类、相似势位）
- 上下游Skill（当前Skill的依赖项/被依赖项）
- 同创作者的其他Skill

#### 5.1.3 数据需求

```typescript
interface Skill {
  id: string;
  name: string;
  category: string;
  creatorId: string;
  createdAt: number;  // 时间步
  currentPotential: number;
  currentPrice: number;
  quality: 'low' | 'medium' | 'high';
  status: 'active' | 'downgraded' | 'forked';
  lifecycle: LifecycleEvent[];

  transactions: Transaction[];
  revenue: RevenueEntry[];
}

interface DerivativeNode {
  skillId: string;
  parentId: string;
  depth: number;           // 衍生深度
  contributionRatio: number; // 对父节点的贡献比例
  potential: number;
  creatorId: string;
  children: DerivativeNode[];
```

### 5.2 模块 6：用户浏览器 + 用户详情

#### 5.2.1 用户浏览器（User Browser）

**定位**：全局可访问的**行为画像库**。穿透任意时间点的辅助视角。

**入口**：
- 顶部全局栏「用户浏览器」按钮（始终可见）
- 推演播放器宏观网络图点击节点
- 资源详情页点击创作者

**布局**：同资源浏览器（三栏：筛选-结果-预览）

**三种视图**：

| 视图 | 描述 | 适用场景 |
|------|------|---------|
| 列表视图 | 表格，列：头像、名称、类型、势位、活跃度、贡献度、影响力 | 对比筛选 |
| 矩阵视图 | 散点图：X=势位，Y=活跃度，气泡大小=影响力，颜色=类型 | 群体分析 |
| 图谱视图 | 力导向图，节点=Agent，边=协作/交易关系 | 社交网络分析 |

**筛选器**：
- 类型：创作者/消费者/中介/治理（多选）
- 势位区间：滑块
- 活跃度：高/中/低（最近50轮的交易次数）
- 信誉分区间：滑块 0-100
- 时间范围：加入生态的时间

**排序**：势位、活跃度、贡献度、影响力、信誉分、加入时间

#### 5.2.2 用户详情（User Detail）— 核心亮点

**定位**：单个 Agent 的**动机-决策-行为完整链条**。雅怡文档强调的核心亮点。

**布局**：
- 顶部：Agent 基本信息（头像、名称、类型、当前势位、信誉分、加入时间）
- 标签页切换：动机层 / 决策层 / 行为层 / 网络层

**动机层（目标函数）**：
- 显示该Agent的**目标函数**（如「最大化收益」、「最大化影响力」、「最大化Skill多样性」）
- 目标函数用**自然语言描述**（来自LLM配置）
- 显示各目标的**权重**（饼图）
- 对比：实际行为与目标函数的**匹配度**（如果Agent说想最大化收益但实际在囤积Skill，匹配度低，标黄）

**决策层（决策日志）**：
- 时间序列：每个时间步的决策记录
- 每条决策显示：
  - 决策类型：生产/消费/衍生/扩展/交易/治理投票
  - 决策对象：Skill ID / Agent ID
  - 决策理由：LLM推理过程的**摘要**（非原始prompt，而是提炼后的自然语言）
  - 预期结果 vs 实际结果（对比）
- 支持筛选：按决策类型、按时间范围、按结果（成功/失败）
- 点击决策 → 展开完整推理链（如果后端存储了详细数据）

**行为层（行为时间轴）**：
- 垂直时间轴，每个事件一个节点
- 事件类型图标：生产（+）、消费（−）、衍生（↗）、扩展（→）、交易（⇄）、降档（↓）、分叉（⚡）
- 点击事件 → 展开详情（时间步、对象、结果、影响）
- 支持「只显示关键事件」过滤

**网络层（上下游关系）**：
- 力导向图，中心=当前Agent，3层上下游
- 上游：谁编排了它（谁买了它的Skill，谁基于它的Skill衍生）
- 下游：它编排了谁（它买了谁的Skill，它基于谁的Skill衍生）
- 边的粗细=交易/衍生次数
- 点击节点 → 跳转到该Agent的**用户详情**（新标签页）
- 点击边 → 显示交易/衍生历史

#### 5.2.3 数据需求

```typescript
interface Agent {
  id: string;
  name: string;
  type: 'creator' | 'consumer' | 'intermediary' | 'governance';
  avatar?: string;
  potential: number;
  reputation: number;       // 信誉分 0-100
  wealth: number;
  joinedAt: number;         // 时间步
  goalFunction: {
    description: string;     // 自然语言描述
    weights: {               // 各目标权重
      wealth: number;
      influence: number;
      diversity: number;
      // ...
    };
    alignment: number;       // 实际行为匹配度 0-1
  };
  decisions: DecisionEntry[];
  behaviorTimeline: BehaviorEvent[];
  network: {
    upstream: NetworkNode[];   // 上游（谁依赖它）
    downstream: NetworkNode[]; // 下游（它依赖谁）
  };
}

interface DecisionEntry {
  timeStep: number;

  expectedOutcome: string;
  actualOutcome: string;
  success: boolean;
}

interface BehaviorEvent {
  timeStep: number;
  type: string;
  skillId?: string;
  agentId?: string;
  amount?: number;
  description: string;
}

interface NetworkNode {
  agentId: string;
  relationType: 'trade' | 'derive' | 'extend' | 'social';
  strength: number;         // 关系强度
  transactionCount: number;
}
```

## 6. 层间联动机制

### 6.1 全局跳转矩阵

| 从 ↓ 到 → | 规则配置 | 推演播放器 | 仪表盘 | 资源浏览器 | 资源详情 | 用户浏览器 | 用户详情 |
|-----------|---------|----------|--------|----------|---------|----------|---------|
| **规则配置** | — | 启动模拟 | — | 预览Skill | 预览详情 | 预览Agent | 预览详情 |
| **推演播放器** | 修改规则 | — | 结束模拟 | 领域下钻 | 节点下钻 | — | 节点下钻 |
| **仪表盘** | 新建实验 | 回放 | — | 异常点下钻 | 异常点下钻 | — | 异常点下钻 |
| **资源浏览器** | — | — | — | — | 点击卡片 | — | 点击创作者 |
| **用户浏览器** | — | — | — | 点击作品 | — | — | 点击卡片 |

### 6.2 关键联动场景（用户旅程）

**场景1：配置时预览**
- 用户在规则配置 Step 2 点击某个 Agent → 右侧属性面板切换为用户详情（预览版，显示预估行为）
- 帮助用户在配置阶段理解 Agent 的潜在行为

**场景2：运行时下钻**
- 用户在推演播放器宏观网络图看到某个 Skill 节点异常发光 → 点击节点 → 右侧滑出资源详情（实时数据，显示当前衍生状态）
- 播放不暂停，支持「边看模拟边看详情」

**场景3：复盘时归因**
- 用户在仪表盘看到 Gini 在 T=87 异常波动 → 点击该时间点 → 跳转到推演播放器（T=87 暂停）→ 发现某个Agent大量降档 → 点击该Agent → 用户详情（查看决策日志：「目标函数冲突导致抛售」）
- 形成完整的「现象→时间→个体→动机」归因链

**场景4：跨资源导航**
- 用户在资源详情页看到衍生树 → 点击某个衍生节点 → 新资源详情页 → 查看其创作者 → 点击创作者 → 用户详情 → 查看该创作者的其他作品 → 点击某个作品 → 另一资源详情页
- 形成「资源→创作者→资源→创作者」的无限导航网络
