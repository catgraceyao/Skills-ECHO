## 一、核心叙事线（3 分钟讲完）

**一句话**：P0 = 创作者发布内容 → 使用者按档位购买 → 链上记录编排 → 势位实时可视化

### 三段式演示

**第一段：创作者侧（发布）**
• 创作者连接钱包 → 上传内容 → 设定四权配置（六档滑动条）
• 系统生成配置哈希 → 上链 → 获得版本节点
• 势位初始化为 0

**第二段：使用者侧（购买+编排）**
• 使用者浏览内容市场 → 按档位购买（禁/己/亲/约/法/公）
• 支付 → 获得许可 NFT → 获得编排权
• 编排内容（引用、组合、扩展）→ 产生编排边

**第三段：系统侧（记录+可视化）**
• 编排边上链 → 触发势位计算
• 势位实时更新（Φ_current += Φ_content × 0.15）
• 可视化仪表盘：势位图、六档分布、Gini 指数

## 四、演示脚本（3 分钟版）

**0:00-0:30 创作者发布**
「创作者 A 上传了一份研究报告，设定四权：所有权=约（可引用但需署名），使用权=法（可商用），衍生权=亲（仅小圈可改编），扩展权=己（不可二次扩展）。系统生成配置哈希上链，初始势位为 0。」

**0:30-1:30 使用者购买+编排**
「使用者 B 购买「法」档位（商用权），支付 0.05 ETH，获得许可 NFT。B 在自己的报告中引用了 A 的研究，产生一条编排边。系统记录：B → A，权重 = Φ_A × 0.15。」

**1:30-2:30 势位演化**
「随着更多使用者引用 A，A 的势位从 0 增长到 12.5。在仪表盘上可以看到：A 的节点变大，颜色从白渐变为青碧，六档分布中「法」档位占比上升，Gini 从 0.38 降到 0.24——生态趋于均匀。」

**2:30-3:00 对比展示**
「如果 A 把所有权降到「公」（完全开放），会发生什么？模拟器显示：ρ 从 67% 升到 89%，Gini 降到 0.12，但 A 的收入下降 40%。创作者需要在开放度和收益之间找到自己的平衡点。」

## 五、技术实现建议

### 前端栈
• React + D3.js（力导向图）
• ECharts（指标仪表盘）
• Web3.js / Ethers.js（链上交互）
• IPFS 网关（内容存取）

### 链上合约交互（P0 最小集）
```solidity
// 创作者发布
CreatorConfig.publishVersion(configJSON, configHash)

// 使用者购买
LicenseToken.mintLicense(to, versionId, expiry, configHash, contractHash)

// 编排记录（P0 简化：链上直接记，不走 ZK）
SGraphCore.createRelation(licenseId, creator, user, ruleHash)

// 势位查询（P0 链下计算，链上抽查）
PotentialEngine.getPotential(creator)
```

### 实时数据流（P0 简化版）
```
编排事件 → 链上日志 → 后端索引（The Graph）→ 前端 WebSocket → 可视化更新
延迟目标：≤ 3 秒
```
