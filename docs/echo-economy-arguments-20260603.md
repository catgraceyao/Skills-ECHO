## 1. 🔴 ECHO 代币去留

**哪吒立场**:MVP纯MEER,双代币设计需调整。

**我的论据**:
- MVP阶段确实应纯MEER,减少认知负担和合规风险
- Phase 2引入ECHO(游戏积分)不是替代MEER,而是**分层设计**:
  - MEER = 链上gas + 质押 + 大额结算(价值存储层)
  - ECHO = 游戏内积分 + 小额奖励 + 贡献值计量(流通层)
- 类比:ETH + USDC 不是替代关系,是不同层。ECHO不发行,只由MEER投注兑换生成,无独立发行权
- 建议:Phase 2文档改为「单代币(MEER)+ 游戏积分(ECHO)」表述,明确ECHO不是独立代币,是MEER的流通映射

**结论**:接受哪吒纯MEER定位,ECHO降级为「游戏积分」而非「代币」,文档措辞调整。

## 2. 🔴 软顶 100,000 ECHO

**哪吒关切**:缺模拟测算,100,000是否合理?

**我的论据**:
- 软顶不是硬上限,是通胀调节触发点。超80%自动衰减,不是封顶
- 测算依据:
  - 假设日活100人,人均日投注1 MEER,日流入100 MEER
  - 势位释放系数0.001,假设高势位节点50个,平均势位500,日释放 = 50×500×0.001 = 25 ECHO
  - 日总发行 ≈ 100 + 25 = 125 ECHO
  - 软顶100,000 ÷ 125 = 800天(约2年)触顶,合理
  - 若日活1000人,约80天触顶,触发衰减,自动调节
- 风险:若早期爆发式增长,衰减机制是否能跟上?建议增加「流通量超50%时提前预警」机制

**结论**:100,000软顶在保守场景(日活100)下合理,但需配套预警机制。建议保留,增加50%预警线。

## 3. 🔴 罚没比例 50%-100%

**哪吒关切**:法律风险高,建议降到30%-80%。

**我的论据**:
- 当前罚没比例:垃圾卡100%、女巫攻击100%、操纵排名80%、刷 fork 50%、审查欺诈50%、串谋100%
- 法律风险分析:
  - 100%罚没 = 全部质押没收,在某些司法管辖区可能被视为「惩罚性过高」
  - 但区块链质押罚没有先例(以太坊Slash 100%存在)
  - 建议分层:主观恶意(串谋/女巫)→ 80%;客观违规(垃圾卡/刷 fork)→ 50%
- 调整方案:
  - SPAM_CARD: 100% → 50%(主观判断边界模糊,降低误伤)
  - DUPLICATE_FORK: 50% → 40%(技术可检测,非恶意)
  - SYBIL_ATTACK: 100% → 80%(明确恶意,但留20%缓冲)
  - RANK_MANIPULATION: 80% → 60%(操纵行为难100%确认)
  - REVIEW_FRAUD: 50% → 40%(主观判断)
  - COLLUSION: 100% → 80%(最严重,但避免极端)

**结论**:接受下调,整体范围调整为40%-80%,降低法律风险,保留威慑力。

## 4. 🟡 创作者治理权门槛

**哪吒建议**:宗师级5000+偏高,建议降到2000+(专家级)。

**我的论据**:
- 当前门槛:新手(0)→进阶(100)→专家(500)→大师(2000)→宗师(5000+)
- 5000势位在测试网阶段几乎无人达到,治理权变成空设
- 降到2000+(专家级)的好处:
  - 专家级在测试网已有可达路径(活跃创作者约2-4周可达)
  - 治理权不是奖励,是责任。门槛太高=没人参与,太低=被刷
  - 2000是「有稳定产出+社区认可」的信号,不是顶级荣誉
- 配套措施:
  - 治理权需额外质押100 MEER(防止为投票而冲势位)
  - 投票权重不与势位线性挂钩,用「势位对数+质押时长」计算

**结论**:接受降到2000+,配套质押要求,防止刷票。

## 5. 🟡 荣誉大使退出机制

**哪吒关切**:不可退出会导致利益固化。

**我的论据**:
- 当前设计:荣誉大使(邀请100+人)永久保留,不可退出
- 利益固化风险:
  - 早期大使占坑,后期新人无法竞争
  - 永久折扣权可能导致大使群体成为「既得利益阶层」
- 建议修改:
  - 荣誉大使改为「终身成就标识」,但折扣权需维持活跃度
  - 具体:荣誉大使若连续180天无邀请,折扣从6折→7折;360天→8折;恢复活跃后重新升回
  - 保留不可退出,但经济特权与活跃度挂钩,防止僵尸大使

**结论**:保留不可退出(荣誉属性),但折扣权与活跃度挂钩,防止利益固化。

## 6. 🟢 反虹吸税 5%

**哪吒关切**:需模拟测算验证比例。

**我的论据**:
- 反虹吸税目的:防止头部卡垄断收益,给新卡生存空间
- 5%测算:
  - 假设头部10%的卡持有40%的总势位
  - 5%额外税从头部抽取,进入公共奖池
  - 测算:若头部卡日均收益10 MEER,5% = 0.5 MEER/天/卡,头部10张 = 5 MEER/天回流公共池
  - 公共池分配给中低势位卡,形成「虹吸→反哺」循环
- 对比方案:3%太弱(头部感知不到),7%太强(头部创作者不满),5%是中间值
- 建议:保留5%,但增加「动态调整」机制--若头部集中度(基尼系数)>0.6,自动升至7%;<0.4,降至3%

**结论**:保留5%,增加动态调整机制,用数据说话而非拍脑袋。

## 7. 🟢 时间衰减半衰期 30天

**哪吒建议**:不同领域衰减速度应不同,建议预留参数化。

**我的论据**:
- 30天半衰期的含义:30天前的贡献权重50%,60天前25%,90天前12.5%
- 领域差异:
  - 代码/开源:长尾效应强,衰减应慢(60天半衰期)
  - 文章/媒体:时效性强,衰减应快(15天半衰期)
  - 设计/艺术:中间值(30天半衰期)
- 参数化方案:
  - 创作者在铸卡时选择「领域类型」→ 链上记录 → 索引器按领域类型选半衰期
  - 领域类型:CODE(60天)、MEDIA(15天)、ART(30天)、MIX(30天)
  - 后续可DAO投票增加新领域
- 技术实现:势位计算在索引器层,链上只存领域类型标识,不存具体半衰期参数

**结论**:接受参数化,按领域类型区分半衰期,链上存领域标识,索引器负责具体计算。

visualTier = floor(semanticTier / semanticMax * 5)

Benefit: visualTier = floor(benefit / 2 * 5) = [0→0, 1→2, 2→5]

## 附录：ERC721 vs ECHO 原生标准 — 哪吒关键提问

> 哪吒："我希望是有自己的一套系统，不要套用 ERC721 的标准。不然的话怎么跨平台使用呢？"

### 现状：三层分离

```
壳：ERC721（兼容层）
  → 钱包认识、交易所认识、OpenSea认识
  → 产权归属：tokenId → owner

魂：IECHOv2License（合约层四权）
  → 不是metadata字段，是合约强制数据结构
  → Usage/Derive/Expand/Benefit 四个uint8字段
  → 合约层可读取、可验证、可强制

势：IPotentialGraph（链下计算+链上存证）
  → 索引器计算，Merkle root上链
  → 钱包看不到，但合约可验证
```

### 哪吒的担忧

**对**：如果钱包只读ERC721，确实看不到四权。用户打开MetaMask，只看到"你拥有这个NFT"，看不到"谁能用/怎么改/收益怎么分"。

**但**：合约层已经"硬"了——四权在合约里，不是metadata。问题在于"呈现层"，不是"协议层"。

### 三种方案对比

|------|------|----------|----------|------|
| **A：轻**（当前） | ERC721 + 合约四权 | 低 | 钱包/交易所天然支持 | 现在 |

**方案A的盲点**：

- 需要独立共识层、验证者网络、桥接
- 与现有生态隔离
