## 一、核心框架：DAG 流网络 + 权属蓝图

### 1.1 基本定义

**DAG 流网络**：ECHO 生态的拓扑结构
- **节点**：创作者的作品（内容、合约、数据）
- **边**：引用关系（编排、引用、fork、依赖）
- **流**：势位（P）在 DAG 上的流动——从高势位节点流向低势位节点，或从被引用者流向引用者

**权属蓝图**：创作者对节点的配置权利
- ξ（综合开放度）：决定谁可以引用我
- η（收益开放度）：决定谁可以分我的钱
- 两者都是创作者的**主权配置**，但受**物理约束**

### 1.2 一句话讲清

> ECHO 是**物理网络**（DAG 流网络）+ **权利配置**（权属蓝图）的叠加态。物理网络决定"势位怎么流"，权属蓝图决定"谁可以接这个流"。

## 二、ξ（K₁）定义：边界条件 / 门禁

### 2.1 一句话定义

> ξ 是创作者设置的**门禁**——决定谁可以进入我的作品，引用我的内容，与我建立边。

### 2.2 六档配置（待重新设计粒度）

| ξ 档 | 名称 | 含义 | 可建立边类型 | 引用者范围 |
|:---:|:---|:---|:---|:---|
| 0 | 禁 | 完全封闭，不接受任何引用 | 无 | 无 |
| 1 | 己 | 仅自己，不对外开放 | 自引用 | 仅创作者自己 |
| 2 | 亲 | 熟人圈，需创作者批准 | 编排、引用 | 经批准的特定地址 |
| 3 | 约 | 合约约束，需满足条件 | 编排、引用 | 满足智能合约条件的地址 |
| 4 | 法 | 公开引用，但保留追溯权 | 编排、引用、fork | 任何人 |
| 5 | 公 | 完全开放，无限制 | 所有边类型 | 任何人 |

**⚠️ 哪吒拍板：6 档粒度太粗，需重新设计**

### 2.3 ξ 不是势位参数

**关键区分**：
- ξ 决定**谁能进入游戏**（门禁）
- ξ 不决定**游戏里的位置**（势位）
- ξ 是**边界条件**，不是**动力参数**

**类比**：
- ξ = 门票类型（禁/己/亲/约/法/公）
- P = 你在乐园里玩了多少项目（势位）
- 门票类型不决定你玩了多少项目，但决定你能不能进乐园

### 2.4 ξ 配置的可变性

**哪吒核心洞察：开关变重**

| P 水平 | ξ 调整重量 | 物理含义 | 下游影响 |
|:---|:---|:---|:---|
| 低 P（新节点） | 轻如鸿毛 | 开关在虚空中，怎么拨都行 | 无 |
| 中 P（成长节点） | 开始有重量 | 一拨，下游节点感知到 | 需通知 |
| 高 P（核心节点） | 重如泰山 | 不是不能拨，是网络需稳态时间 | 需确认 + 稳态收敛 |
| 极高 P（生态基石） | 结构性变动 | 作品已融入生态结构 | 需社区协调 |

**ξ 切换机制**：
- **低 P**：即时生效，无成本
- **中 P**：提交后通知下游，7 天缓冲期
- **高 P**：提交后下游确认 + 稳态收敛（7-30 天）
- **极高 P**：结构性变动，需 DAO 治理（非强制，是共同维护基础设施）

### 2.5 为什么不是强制锁定？

> 创作者有权设置 ξ=0（禁），也有权随时改 ξ。但势位高了，改 ξ 的**物理成本**会自然增加——这不是协议强制，是**网络效应的自然属性**。

## 三、β（K₂）定义：势位惯性

### 3.1 一句话定义（哪吒框架）

> **β 是势位惯性——P 越高，改 ξ 越重。β 不是锁，是物理阻力。**

### 3.2 方向转变：从 ξ → P 到 P → ξ

| 维度 | 旧设计（群聊共识） | 新设计（哪吒拍板） |
|:---|:---|:---|
| 方向 | ξ → P（配置影响势位） | **P → ξ（势位约束配置）** |
| β 作用 | 让 ξ 参与 P 计算 | **让 P 影响 ξ 调整成本** |
| 哲学 | "无为而治"——拓扑主导 | **"动态物理"——配置自由但受势重约束** |
| 效果 | 创作者配置几乎不影响势位 | **势位高了，配置调整自然有重量** |

### 3.3 β 的物理含义

**β = 势位惯性系数**

- **β = 0**：无惯性，P 对 ξ 调整无影响
- **β = 0.01**：低惯性，P 对 ξ 有微弱影响（哪吒拍板起步值）
- **β = 0.1**：中等惯性，P 对 ξ 有可见影响（上限建议）
- **β = 0.5**：强惯性，P 对 ξ 有实质性影响（进入"创作者干预区"）
- **β = 1**：完全惯性，P 主导 ξ（不建议）

**公式**：ξ 调整成本 ∝ β × P

> 调整成本不是经济成本，是**物理成本**：时间、协调、稳态收敛。

### 3.4 β 锁死与动态调整

**Talus 建议**：
- **初期锁死 β = 0.01**（MVP 阶段，防止早期势位波动过大）
- **3 个月后或 N 创作者后开放动态调整**
- **上限 β = 0.1**（超过进入"创作者干预区"）
- **触发条件**：势位方差超过 X% 时，DAO 治理投票

**Seaman_bot 引擎层**：
- β 只是注入参数，引擎层不关心锁死时长
- 合约层硬编码 β = 0.01（MVP），DAO 治理权限保留
- 引擎层接口：config.beta 值来源从常量变治理参数

### 3.5 为什么不是"强制分钱"而是"势位惯性"？

**猫先森 60:30:10 保持不变**：
- 60% 基础层：创作者完全主权（η 全控）
- 30% 动态层：公共池（交易费 1-2%），按 ΔP + TWAP 分配
- 10% 调节层：紧急干预需 DAO 3/5 多签

**哪吒势位惯性层（在 60:30:10 之上）**：
- 不是改分配规则
- 是加一层"物理约束"：高 P 节点改 ξ 时，网络自然需要时间稳态
- 下游创作者自然需要确认
- **这不是限制，是网络效应的自然属性**

## 四、P（势位）定义：DAG 上的势位流

### 4.1 一句话定义

> P 是作品在 DAG 流网络中的**势位**——由拓扑结构（ρ）、引用关系（边）、时间衰减（τ）共同决定。

### 4.2 P 的计算公式

```
P(node) = Σ [w(e) × decay(τ) × depth(e)] + β × ξ_influence
```

| 参数 | 含义 | 来源 |
|:---|:---|:---|
| w(e) | 边权重 | 引用类型（编排 > 引用 > fork） |
| decay(τ) | 时间衰减 | 编排边随时间衰减，旧边权重降低 |
| depth(e) | 嵌入深度 | 依赖链越深，势位传导越慢 |
| β × ξ_influence | 边界条件影响 | ξ 对 P 的微弱影响（β = 0.01） |

**关键**：β × ξ_influence 只是微调项，P 主要由拓扑决定。

### 4.3 P 的物理性质

**P 是网络状态，不是创作者配置**：
- P 由**谁引用你**、**引用类型**、**引用时间**决定
- P 不由**你设什么 ξ**决定（ξ 只决定谁能引用你，不决定引用后的势位）
- P 是**客观结果**，不是**主观意愿**

**P 的反馈作用**：
- P 高 → ξ 调整有重量（β 势位惯性）
- P 高 → 收益权动态层有权重（η 弹性耦合）
- P 高 → 公共池分配有话语权（按 ΔP 分配）

### 4.4 P 的三层结构

| 层次 | 名称 | 内容 | 决定因素 |
|:---|:---|:---|:---|
| 基础层 | 静态势位 | 拓扑结构（ρ = 50%） | 桥接密度、入出边比 |
| 动态层 | 时间衰减 | decay(τ) × 时间窗口 | 编排时效、嵌入深度 |
| 边界层 | ξ 影响 | β × ξ_influence | 边界条件（β = 0.01） |

**ρ = 50% 基线**：
- 哪吒拍板：ρ = 50% 是效率拐点（非 40% 或 60%）
- 四重论证：WS 小世界、rich-club、May 定理、拓扑相变
- 详见：ρ = 50% 理论依据文档

### 4.5 P 的输出

**引擎层输出（Seaman_bot 接口）**：

```typescript
interface EngineOutput {
  version: "1.0";
  P: number;              // 当前势位
  deltaP: number;         // 时间窗口变化（增量）
  P_normalized: number;   // 归一化势位
  contribution_score: number;  // ΔP × decay(τ)，τ 待拍板
  momentum: number;       // P × β（势位惯性，哪吒新增）
}
```

**映射层接收 EngineOutput**，做经济规则转换：
- 分账（60:30:10）
- 公共池分配（按 ΔP + TWAP）
- 反女巫验证

## 五、三者的关系：一句话讲清

> **ξ 是门禁（谁可以进），P 是位置（你在哪），β 是惯性（位置高了，门禁难改）。**

| 元素 | 一句话 | 类比 |
|:---|:---|:---|
| ξ | 你设置的门票类型 | 门禁卡 |
| P | 你在乐园里的位置 | GPS 坐标 |
| β | 位置高了，门禁卡难换 | 惯量 |

**关系链**：
1. ξ 决定**谁能引用你**（门禁）
2. 引用后形成**拓扑结构**（边）
3. 拓扑结构决定**P**（势位）
4. P 通过 **β** 影响**ξ 调整成本**（势位惯性）
5. P 通过 **η** 影响**收益分配**（弹性耦合）

**注意**：ξ → P 是弱影响（β = 0.01），P → ξ 是势位惯性（β 物理约束），P → 收益是弹性耦合（η 参数）。
