## 一、价格显示机制（v0.3 简化）

### 1.1 问题回顾
v0.2 采用方案 B（固定 MEER + 波动提示），但讨论后确认：游戏内经济循环纯 MEER 即可，法币波动不影响核心玩法。

### 1.2 v0.3 决策：纯 MEER 循环 + USD 参考显示

**核心原则**：
- 游戏内所有定价（投注、皮肤、大使）均以 **MEER** 计价
- USD 价格仅作**前端参考显示**，不进入核心经济逻辑
- 法币波动只影响用户法币退出时的价值感知，不影响游戏内公平性

**USD 参考显示（增值功能，非核心）**：
- 数据源：CoinGecko API 或 CMC API（单源即可，非关键）
- 更新频率：每 6 小时（或按需）
- 显示方式：前端标注「≈ X USD」，灰色小字提示
- 异常处理：API 失效时隐藏 USD 显示，不影响任何核心功能
- 技术实现：
  ```python
  # 可选的 USD 显示逻辑
  def get_usd_reference():
      try:
          price = fetch_coingecko_price()  # 或 CMC
          return f"≈ {bet_amount * price:.2f} USD"
      except:
          return ""  # 静默失败，不显示
  ```

### 1.3 投注额度（纯 MEER 固定）

| 场景 | 最低投注 | 封顶投注 | 说明 |
|------|---------|---------|------|
| 正常 | 0.1 MEER | 10 MEER | 固定 MEER，无 USD 波动影响 |
| 异常 | 0.05 MEER | 5 MEER | 手动降级（Owner 或 DAO 触发） |
| 暂停 | 关闭投注 | 关闭投注 | 合约层自动熔断触发 |

## 二、防攻击机制升级（v0.3）

### 2.1 合约层自动熔断（v0.3 新增）

v0.2 熔断是手动/半自动，v0.3 引入合约层自动熔断。

```solidity
// 熔断合约逻辑
contract GameCircuitBreaker {
    uint256 public constant HIGH_BET_THRESHOLD = 100 * 1e18; // 100 MEER
    uint256 public constant HIGH_WIN_RATE = 80; // 80%
    uint256 public constant LOW_POOL_BALANCE = 5 * 1e18; // 5 MEER
    
    bool public isPaused;
    uint256 public consecutiveHighWinRounds;
    
    modifier checkCircuit() {
        require(!isPaused, "Game paused");
        _;
    }
    
    function placeBet() external checkCircuit {
        // 检查单轮投注额
        if (totalRoundBet > HIGH_BET_THRESHOLD) {
            pauseGame();
        }
    }
    
    function settleRound() external {
        // 检查胜率
        if (winRate > HIGH_WIN_RATE) {
            consecutiveHighWinRounds++;
            if (consecutiveHighWinRounds >= 3) {
                pauseGame();
            }
        } else {
            consecutiveHighWinRounds = 0;
        }
        
        // 检查奖池余额
        if (poolBalance < LOW_POOL_BALANCE) {
            pauseGame();
        }
    }
    
    function pauseGame() internal {
        isPaused = true;
        emit GamePaused(block.timestamp, reason);
    }
    
    function resumeGame() external onlyOwner {
        isPaused = false;
    }
}
```

## 三、卡牌皮肤市场规则（v0.3 新增）

### 3.1 审查机制

**审查标准**：
- 不侵犯版权（原创或授权）
- 不含敏感内容（政治、色情、暴力）
- 符合 ECHO 品牌调性（科技、未来、去中心化）
- 文件格式：SVG 或 PNG，大小 < 500KB

**审查流程**：
1. 创作者提交皮肤（IPFS 存储）
2. 社区投票（7 天，> 50% 同意 + > 10 票）
3. 通过则上架，不通过则退回
4. 首次上架免审（创作者历史无违规）

**审查主体**：
- 初期：协议团队（3 人小组）
- 后期：社区自治（质押 100 MEER 成为审查员）

### 3.2 经济模型

| 项目 | 费率 | 说明 |
|------|------|------|
| 皮肤售价 | 创作者自定 | 范围 0.01-10 MEER |
| 协议抽成 | 10% | 维护和激励 |
| 创作者收入 | 90% | 即时到账 |
| 版税 | 2% | 每次转售，归原作者 |

### 3.3 皮肤等级

| 等级 | 获取方式 | 特效 |
|------|---------|------|
| 基础 | 免费 | 单色边框 |
| 稀有 | 购买 | 银边 + 粒子 |
| 史诗 | 购买 | 金边 + 动态背景 |
| 传说 | 购买或成就 | 虹彩 + 全屏特效 + 专属编号 |

## 四、大使体系完善（v0.3）

### 4.1 审核标准

**自动晋升**：
- 邀请 31+ 人
- 被邀请者完成 ≥ 3 轮投注
- 被邀请者持仓 > 0.1 MEER
- 满足条件则自动晋升（无需人工审核）

**人工审核场景**：
- 邀请质量异常（被邀请者 3 轮内流失率 > 80%）
- 涉嫌刷邀请（同一设备/IP 邀请 > 5 人）
- 社区投诉（不当推广行为）

### 4.2 退出机制（v0.3 新增）

| 退出类型 | 触发条件 | 后果 |
|---------|---------|------|
| 主动退出 | 大使申请 | 失去大使卡，手续费恢复 100% |
| 被动退出 | 连续 90 天无邀请 | 失去大使卡，保留手续费 9 折 |
| 强制退出 | 违规刷邀请 | 没收大使卡，手续费恢复 100% |
| 荣誉保留 | 邀请 100+ 人 | 永久保留大使身份，不可退出 |

### 4.3 大使特权更新

| 特权 | v0.2 | v0.3 |
|------|------|------|
| 手续费折扣 | 8 折 | 8 折（永久） |
| 专属卡牌 | 有 | 有（不可交易） |
| 优先内测 | 有 | 有 |
| 季度空投 | 大使人数 × 0.01 MEER | 大使人数 × 0.01 MEER + 贡献值加成 |
| 新特权 | 无 | 皮肤市场优先上架权 |
