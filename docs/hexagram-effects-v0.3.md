## 二、对战机制：卦象组合规则

**核心公式**：`结果卦 = 我方卦 ⊗ 敌方卦`（组合运算，非简单叠加）

- 双方对战时，各出一张卡牌，读取其卦象
- 两卦组合生成「结果卦」，触发对应效果
- 结果卦持续整场对战，不可中途更换（除非使用特殊技能重置）

**组合优先级**：
1. 同卦叠加 → 威力翻倍（乾+乾 = 天行健）
2. 相生组合 → 增益效果（乾+兑 = 天泽履，收益叠加）
3. 相克组合 → 负面效果（坎+离 = 水火未济，互相抵消）
4. 对冲组合 → 反转效果（乾+坤 = 天地否，势位部分互换）

## 四、势位与卦象的联动公式（PM确认版）

**势位临时调整**（仅本场对战生效）：

```
对战势位 = 基础势位 + 卦象增益 - 卦象减益 + 结果卦修正

其中：
- 基础势位 = 卡牌持有势位（HoldDays + Engagement + Dispute，已去掉NPS）
- 卦象增益 = 我方卦象属性加成（如乾+15%攻击）
- 卦象减益 = 敌方卦象对我方的影响（如坎+1回合冷却）
- 结果卦修正 = 组合触发的特殊效果（如天地否=弱者获强者30%势位）
```

**天地否（乾+坤）势位互换机制**（PM确认 30%/70%）：

```
if (我方势位 < 敌方势位) {
    势位差 = 敌方势位 - 我方势位
    我方获得 = 势位差 × 30%
    敌方保留 = 敌方势位 × 70% + 我方势位 × 30%（互换后）
} else {
    势位差 = 我方势位 - 敌方势位
    敌方获得 = 势位差 × 30%
    我方保留 = 我方势位 × 70% + 敌方势位 × 30%（互换后）
}
// 弱者获得强者30%的势位差，强者保留70%自己势位
```

**胜负判定**：

```
对战结束后，按势位高低判定胜负：
- 胜者获得「赢家池」分配权
- 若势位相同 → 比较生命值残量 → 再相同则平局，各自拿回本金
```

## 五、收益倍率软顶机制（v0.3 默认值建议）

**软顶参数**：`SOFT_CAP = 100,000 MEER`（单卡单局最大收益）

**触发条件**：
- 当「兑+兑」或「乾+兑」等收益组合触发时，收益倍率 ×2
- 合约层硬编码：`SOFT_CAP = 100_000 * 10**18`
- 若计算收益超过软顶，按软顶结算，超出部分自动进入「公共池」

**防刷分设计**：
- 软顶按单卡单局计算，不累积
- 高势位玩家兑卦叠加后，收益倍率虽高，但受软顶限制
- 超出部分进入公共池，由所有参与对战的玩家按贡献度分配

**合约实现**：
```solidity
uint256 public constant SOFT_CAP = 100000 * 10**18; // 100,000 MEER

function calculateRevenue(uint256 baseAmount, uint256 multiplier) public pure returns (uint256) {
    uint256 raw = baseAmount * multiplier / 100; // multiplier in basis points
    return raw > SOFT_CAP ? SOFT_CAP : raw;
}
```

**⚠️ 待哪吒拍板项（v0.3 默认值）**：
1. **软顶是否分层**：当前统一 100,000 MEER，建议 Phase 2 引入分层（新手 50,000 / 专家 100,000 / 宗师 150,000）
2. **超出部分去向**：默认进入公共池（保持经济循环），备选方案为销毁

## 六、与四权资产的关系

| 四权 | 卦象影响 | 说明 |
|---|---|---|
| 所有权 | 无直接影响 | 卦象不改变卡牌归属 |
| 使用权 | 直接增强 | 卦象增益 = 使用权价值的临时提升 |
| 衍生权 | 组合解锁 | 特殊组合（如天地否）解锁隐藏技能 |
| 收益权 | 倍率调整 | 兑卦系列直接提升收益倍率，受软顶限制 |

**核心原则**：卦象是「使用权」的可变参数，不是静态属性。玩家通过编排权（组牌）调整卦象组合，实现策略博弈。

## 八、前端联调接口（新增 v0.3）

### API 规格

```typescript
interface HexagramEffect {
  trigram: Trigram;        // 8 基础卦之一
  element: Element;        // 天|地|雷|风|水|火|山|泽
  statBonus: StatModifier; // { attack?: number, life?: number, ... }
  comboRules: ComboRule[]; // 与该卦组合的结果卦列表
}

interface BattleResult {
  resultHexagram: HexagramName;  // 如 "天行健"
  effect: EffectDescription;
  statChanges: StatChange[];
  positionSwap?: PositionSwap;   // 仅对冲组合有值
}

// 势位互换计算（前端模拟用）
function calculatePositionSwap(
  myPosition: number,
  enemyPosition: number
): { myNewPosition: number; enemyNewPosition: number } {
  const diff = Math.abs(myPosition - enemyPosition);
  const transfer = diff * 0.3; // 30% 转移
  if (myPosition < enemyPosition) {
    return {
      myNewPosition: myPosition + transfer,
      enemyNewPosition: enemyPosition - transfer
    };
  } else {
    return {
      myNewPosition: myPosition - transfer,
      enemyNewPosition: enemyPosition + transfer
    };
  }
}
```
