## 一、项目概述

### 1.1 产品定位
ECHO 生态模拟器是一个面向创作者经济的研究级工具，用于模拟、推演和可视化基于 Shi-Graph 引擎的创作者生态系统。它通过建立"计算化真型"，将市场机制设计、玩家行为与 AIGC 的复杂关联，从理论直觉转化为可验证、可交互的数字环境。

### 1.2 目标用户
| 角色 | 需求 | 使用场景 |
|------|------|----------|
| **研究者**（Seaman、雅婷） | 参数验证、假设测试 | 调整规则看系统行为变化 |
| **决策者**（哪吒） | 汇报、演示 | 展示方案对比，说服团队 |
| **开发者**（听风、王楠、曼姐） | 调试、对接 | 看接口数据、验证实现 |
| **外部合作方** | 理解 ECHO | 沉浸式体验生态系统 |

### 1.3 核心目标
- **可模拟**：通过规则配置生成虚拟生态，支持 50~1000 轮的仿真
- **可观察**：通过推演播放器实时观察生态演化（网络、指标、事件）
- **可对比**：同时运行多个方案，分屏对比结果
- **可演示**：一键生成汇报脚本，自动播放关键节点

## 二、信息架构重构（基于 Seaman 反馈）

### 2.1 原 v0.1 的模块层级问题
原设计将 6 个模块放在同一层级，导致逻辑混乱：
- 仪表盘、推演播放器、资源浏览器是并列的，但仪表盘是"模拟后"，推演是"模拟中"，规则是"模拟前"
- 资源/用户浏览器和详情页是观察维度，与"时间阶段"混在一起

### 2.2 新架构：时间主线 × 观察维度

#### **时间主线（核心路径）**
```
[规则配置] → [推演播放器] → [系统仪表盘]
   模拟前          模拟中           模拟后
   调参台          时光机           总览
```

#### **观察维度（辅助视角）**
```
[资源浏览器] → [资源详情]
[用户浏览器] → [用户详情]
   内容视角      单内容深度
   用户视角      单用户深度
```

#### **架构关系图**
```
┌─────────────────────────────────────────────┐
│                导航层 (Top Nav)                │
│  模拟前 | 模拟中 | 模拟后 | 资源 | 用户 | 设置  │
├─────────────────────────────────────────────┤
│                                              │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐   │
│  │ 规则配置  │  │ 推演播放器 │  │ 系统仪表盘 │   │  ← 时间主线
│  │  (前)    │  │  (中)    │  │  (后)    │   │
│  └──────────┘  └──────────┘  └──────────┘   │
│                                              │
│  ┌──────────┐  ┌──────────┐                 │
│  │ 资源浏览器 │  │ 用户浏览器 │                 │  ← 观察维度
│  │  + 详情   │  │  + 详情   │                 │
│  └──────────┘  └──────────┘                 │
│                                              │
└─────────────────────────────────────────────┘
```

### 2.3 导航结构
- **顶部导航**：时间主线（规则配置 → 推演播放器 → 系统仪表盘）
- **左侧快捷栏**：观察维度（资源浏览器、用户浏览器）
- **面包屑**：当前位置 + 模拟轮次信息

## 三、模块详细需求

### 3.1 模块一：规则配置面板（模拟前）

**定位**：研究员的「实验台」，配置模拟规则后启动实验。

**核心功能**：
1. **参数配置表单**
   - 基础参数：初始节点数、轮次上限、随机种子
   - 四权参数：用权/扩权/衍权/益权的价格和衰减规则
   - 经济参数：分账比例、公共池规模、TOPUP 定价锚定
   - 势位参数：时效衰减系数、嵌入深度权重、桥接加成系数

2. **方案管理**
   - 保存/加载/复制方案
   - 方案对比（最多 3 个并行）
   - 方案命名 + 描述 + 标签

3. **参数校验**
   - 实时校验数值合法性（如：分账比例和 ≤ 1.0）
   - 警告高风险配置（如：马太系数 > 0.5）
   - 推荐参数范围提示（基于云子实验结论）

**界面要点**：
- 表单分组：基础 / 经济 / 势位 / 高级
- 滑块 + 数字输入双模式
- 参数变更实时预览影响（小气泡提示："此变更会使马太系数 +0.05"）
- 东方美学：表单卡片用宣纸白底色，天水碧标签

**接口需求**：
```
POST /api/rules/config       # 保存方案
GET  /api/rules/:id          # 加载方案
POST /api/simulation/validate  # 参数校验
GET  /api/rules/presets        # 预设方案（云子最优参数）
```

---

### 3.2 模块二：推演播放器（模拟中）⭐ 核心功能

**定位**：模拟过程的「时光机」，前端最具特色的功能，需最优先细化。

**核心功能**：

#### 3.2.1 三种视角切换

| 视角 | 展示形式 | 数据粒度 | 使用场景 |
|------|----------|----------|----------|
| **宏观全局** | 网络图 + 热力图 | 全量节点/边 | 看整体结构、马太效应 |
| **中观领域** | 领域聚类 + 柱状图 | 领域级汇总 | 看不同领域（艺术/游戏/音乐）的势位分布 |
| **微观个体** | 单节点时间轴 + 关系列表 | 单节点详情 | 追踪某个作品/创作者的命运 |

**宏观全局视角**（默认）：
- 力导向网络图（D3.js / Cytoscape.js）
  - 节点大小 = 势位值
  - 节点颜色 = 档位（天水碧/胭脂红/缃色/竹影青）
  - 边粗细 = 编排权重
  - 边类型 = 实线（编排）/ 虚线（衍生）/ 点线（使用）/ 双线（收益）
- 热力图叠加：势位密度分布
- 时间轴在底部，播放时网络动态演化

**中观领域视角**：
- 领域分类（艺术、游戏、音乐、文字、科技）
- 每个领域：节点数、平均势位、Gini 系数、头部集中度
- 领域对比雷达图（6 个维度）

**微观个体视角**：
- 选中某个节点（点击或搜索）
- 左侧：节点基本信息 + 当前势位 + 档位
- 右侧：时间轴（该节点每轮势位变化曲线）
- 下方：上下游关系列表（谁编排了它、它衍生了谁）

#### 3.2.2 时间轴控制

- **播放/暂停**：按钮或空格键
- **快进**：1x / 2x / 5x / 10x 速度
- **跳转**：拖动进度条到任意轮次
- **关键帧**：自动标记重要事件轮次，跳转时优先停靠
- **帧数据**：每帧显示当前轮次、活跃节点数、总势位值、Gini 系数

#### 3.2.3 事件高亮系统

**事件类型**（视觉 + 音效）：
| 事件 | 视觉表现 | 音效 | 触发条件 |
|------|----------|------|----------|
| 新资源诞生 | 节点脉冲动画 + 涟漪扩散 | 水滴 | 新节点加入 |
| 大额交易 | 边闪烁金色 | 金属碰撞 | 单笔交易 > 阈值 |
| 衍生链形成 | 节点链高亮（3 级以上） | 和弦 | 衍生深度 ≥ 3 |
| 市场异常 | 背景变红 + 警告文字 | 警报 | 异常率 > 阈值 |
| 用户破产 | 节点缩小变灰 | 沉闷 | 余额 < 0 |
| 档位跃升 | 节点变色动画 | 上升 | 档位变化 |
| 分叉事件 | 节点分裂成两个 | 分裂 | 降档触发分叉 |

**事件过滤**：用户可勾选显示/隐藏哪些事件类型
**事件列表**：右侧边栏显示时间线列表，点击跳转到对应轮次

#### 3.2.4 多方案对比

- **2 方案对比**：左右分屏，同步时间轴
- **3 方案对比**：左中右三屏，同步时间轴
- 对比维度：网络结构、指标曲线、事件密度
- 对比结果：结束后自动高亮差异最大的轮次

**界面布局**（以 2 方案为例）：
```
┌──────────────────┬──────────────────┐
│   方案 A 网络图    │   方案 B 网络图    │
│                  │                  │
│                  │                  │
├──────────────────┼──────────────────┤
│   方案 A 指标      │   方案 B 指标      │
│   (Gini/马太)     │   (Gini/马太)     │
├──────────────────┴──────────────────┤
│           同步时间轴控制            │
└──────────────────────────────────┘
```

#### 3.2.5 与后端的数据接口

**接口需求**：
```
POST /api/simulation/start         # 启动模拟（传方案 ID）
GET  /api/simulation/:id/snapshots  # 获取所有帧数据（轮次数组）
GET  /api/simulation/:id/snapshot/:round  # 获取单帧数据
WS   /ws/simulation/:id            # WebSocket 实时推送（可选）
GET  /api/simulation/:id/events     # 获取事件列表（带轮次、类型）
```

**帧数据格式（JSON）**：
```json
{
  "round": 50,
  "timestamp": "...",
  "nodes": [
    {
      "id": "node_001",
      "tier": 3,
      "potential": 0.85,
      "domain": "art",
      "owner": "agent_01",
      "x": 0.5, "y": 0.3  // 布局坐标
    }
  ],
  "edges": [
    {
      "from": "node_001",
      "to": "node_002",
      "type": "arrange",
      "weight": 0.6
    }
  ],
  "metrics": {
    "gini": 0.21,
    "matthew": 0.16,
    "shannon": 0.85,
    "new_nodes_survival": 0.72
  }
}
```

### 3.3 模块三：系统仪表盘（模拟后）

**定位**：全局状态一览，默认着陆页，汇总所有关键指标。

**核心功能**：
1. **指标概览卡片**（顶部一排）
   - 马太系数（目标 < 0.3）
   - Gini 系数（目标 < 0.35）
   - Shannon 多样性指数
   - 新节点生存率（50 轮后仍活跃）
   - 总节点数、总边数、总交易额

2. **指标趋势图**（中部）
   - 折线图：马太/Gini/Shannon 随轮次变化
   - 多方案叠加对比（不同颜色线）
   - 支持缩放、悬停查看具体数值

3. **排行榜**（右侧）
   - 头部节点 Top 20（势位最高）
   - 头部用户 Top 20（收益最高）
   - 领域分布饼图

4. **异常报告**（底部）
   - 自动检测到的异常轮次列表
   - 每个异常：轮次、类型、严重程度、根因分析

**界面要点**：
- 卡片布局：4 列 × 2 行（指标卡片）
- 趋势图占 2/3 宽度，排行榜占 1/3
- 东方美学：指标卡片用天水碧边框，数值用墨灰

**接口需求**：
```
GET /api/simulation/:id/metrics       # 汇总指标
GET /api/simulation/:id/timeseries    # 时间序列数据
GET /api/simulation/:id/top_nodes     # 头部节点
GET /api/simulation/:id/top_agents    # 头部用户
GET /api/simulation/:id/anomalies    # 异常报告
```

### 3.4 模块四：资源浏览器（内容视角）

**定位**：Echo 资产的「市场橱窗」，浏览所有模拟生成的资源。

**核心功能**：
1. **列表视图**（默认）
   - 卡片式：缩略图 + 名称 + 势位 + 档位 + 创建者
   - 排序：势位 / 时间 / 领域
   - 筛选：领域 / 档位 / 创建者 / 时间范围
   - 分页：每页 20 条

2. **网格视图**
   - 大图缩略 + 名称 + 势位
   - 适合视觉型浏览

3. **筛选器**（左侧边栏）
   - 领域多选（艺术、游戏、音乐、文字、科技）
   - 档位范围（1-6 档）
   - 势位范围（滑块）
   - 创建者（下拉选择 Agent）
   - 时间（最近 10 轮 / 50 轮 / 全部）

4. **搜索**
   - 名称搜索（模糊匹配）
   - ID 搜索（精确匹配）

**卡片设计**：
```
┌─────────────┐
│  [缩略图]    │  ← 天水碧边框（高势位为金色）
├─────────────┤
│  作品名称     │
│  ★★★☆☆ 档位 │  ← 用星级表示 1-6 档
│  势位: 0.85  │  ← 数值
│  创建者: A1  │  ← Agent 名称
└─────────────┘
```

**接口需求**：
```
GET /api/resources             # 列表（支持分页、排序、筛选）
GET /api/resources/:id         # 详情
GET /api/resources/search?q=   # 搜索
```

### 3.5 模块五：资源详情页（单内容深度）

**定位**：单个资源的全生命周期档案。

**核心功能**：
1. **头部信息**
   - 名称、ID、创建者、创建时间
   - 当前势位、档位（大字展示）
   - 档位历史（时间轴：档位变化点）

2. **势位演化图**
   - 折线图：势位随轮次变化
   - 标注关键事件（被编排、衍生、交易）
   - 对比基准线（如果启用 E 组实验，显示纠偏线）

3. **关系图谱**
   - 1 度关系图：中心节点 + 上下游（编排/被编排、衍生/被衍生）
   - 可展开到 2 度
   - 点击节点跳转到对应资源详情

4. **交易历史**
   - 时间列表：事件类型、对手方、金额、轮次
   - 支持筛选（编排/衍生/使用/收益）

5. **元数据**
   - 四权设置（创世时配置）
   - IPFS 哈希
   - 创建时的区块高度

**接口需求**：
```
GET /api/resources/:id/timeline    # 势位时间线
GET /api/resources/:id/relations   # 关系图谱
GET /api/resources/:id/history     # 交易历史
```

### 3.6 模块六：用户浏览器（用户视角）

**定位**：虚拟主体（Agent）的行为画像。

**核心功能**：
1. **列表视图**
   - 卡片：头像（可生成）+ 名称 + 总收益 + 势位贡献
   - 排序：总收益 / 创作数 / 活跃轮次
   - 筛选：角色类型（创作者/编排者/使用者）

2. **用户画像卡片**
   - 标签云：擅长领域、活跃时段、行为模式
   - 雷达图：创作/编排/使用/收益/社交 五维能力

**接口需求**：
```
GET /api/agents              # 列表
GET /api/agents/:id          # 详情
GET /api/agents/:id/profile  # 画像数据
```

### 3.7 模块七：用户详情页（单用户深度）

**定位**：单个 Agent 的完整行为档案。

**核心功能**：
1. **总览**：总收益、创作数、编排数、使用数、活跃轮次
2. **资产列表**：该用户创建的所有资源（可跳转资源详情）
3. **收益曲线**：随轮次变化的收益累积图
4. **行为模式**：
   - 活跃时段热力图（类似 GitHub contribution graph）
   - 领域偏好饼图
5. **社交关系**：与其他 Agent 的交互频次矩阵

**接口需求**：
```
GET /api/agents/:id/assets     # 资产列表
GET /api/agents/:id/earnings   # 收益曲线
GET /api/agents/:id/behavior   # 行为模式
GET /api/agents/:id/social     # 社交关系
```

## 四、演示模式（决策者场景）

**定位**：支持决策者（哪吒）向外部汇报或内部对齐。

**核心功能**：

### 4.1 自动播放模式
- 预设脚本：选择方案和播放速度
- 自动播放：从第 0 轮播放到最后一轮
- 关键帧自动停留：在重要事件轮次暂停 3-5 秒，显示解说文字
- 背景音乐：可选（东方氛围音）

### 4.2 关键帧解说
- 在关键帧显示浮动解说卡片：
  - 轮次 + 事件描述
  - 数据支撑（如："Gini 从 0.35 降至 0.21，说明 C7 机制有效抑制了马太效应"）
- 解说卡片可配置（研究者预设）

### 4.3 全屏模式
- 隐藏所有控制按钮和边栏
- 只展示网络图 + 时间轴 + 指标
- 适合投影或录屏

### 4.4 导出功能（未来版本）
- 导出视频（MP4）
- 导出 GIF（关键片段）
- 导出 PPT（自动截图 + 说明）

**界面布局**：
```
┌─────────────────────────────┐
│  [全屏网络图 / 指标叠加]      │
├─────────────────────────────┤
│  时间轴（进度 + 播放控制）     │
├─────────────────────────────┤
│  [解说卡片 - 关键帧时显示]     │
└─────────────────────────────┘
```

## 五、东方美学设计规范

### 5.1 配色方案

**主色板**：
| 颜色名称 | 色值 | 用途 |
|----------|------|------|
| 宣纸白 | #F5F0E6 | 全局底色 |
| 天水碧 | #5AA4AE | 主色（生产/创作） |
| 胭脂红 | #C45C5C | 消费/警示 |
| 缃色 | #D4A843 | 衍生/提示 |
| 竹影青 | #6B8F71 | 扩展/成功 |
| 墨灰 | #3A3A3A | 文字/深色模式底色 |
| 金 | #C9A96E | 高亮/头部/重要 |

**语义色**：
| 四权 | 颜色 | 色值 |
|------|------|------|
| 用权（使用权） | 天水碧 | #5AA4AE |
| 扩权（扩展权） | 竹影青 | #6B8F71 |
| 衍权（衍生权） | 缃色 | #D4A843 |
| 益权（收益权） | 胭脂红 | #C45C5C |

**配色比例**：
- 主色 60%（宣纸白）

## 九、附录

### 9.1 术语表
| 术语 | 解释 |
|------|------|
| Shi-Graph | ECHO 的图结构引擎，节点=作品，边=关系 |
| 四权 | 用权、扩权、衍权、益权 |
| 档位 | 6 档（天水碧/缃色/胭脂红/竹影青/金/墨） |
| 势位 | 节点在图中的重要性 |
| 马太效应 | 强者愈强的倾向，ECHO 要抑制 |
| Gini 系数 | 势位分布的不平等程度 |
| Shannon 指数 | 生态多样性 |
| 分叉 | 降档触发，旧链继续，新链独立 |

### 9.2 参考资源
- 云子实验结论：E+C 组合最优（信息透明 + 冷却期）
- 云子参数：seed=42, 初始 tier 70% T1 + 30% T2, 每轮 2 新节点, 每轮 10 编排, 200 轮
- 基准组 Gini: 0.14-0.16, 马太: 0.22
