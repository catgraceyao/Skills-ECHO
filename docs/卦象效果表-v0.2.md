## 一、字段定义

| 字段 | 说明 | 数据类型 | 示例 |
|------|------|---------|------|
| 卦名 | 64卦名称 | string | 乾为天 |
| 卦象 | 上下卦组合 | string | 乾上乾下 |
| 势位增益 | 对势位排名的加成系数 | float | 1.15 |
| 对战效果 | 对战中触发的特殊效果 | string | 先手攻击+10% |
| 基础权重 | 随机出现概率基准值 | float | 0.0156 |
| 动态调整因子 | 基于使用率/胜率的动态权重调整 | float | ±0.005 |
| MEER消耗 | 激活该卦象的成本 | float | 0.5 |
| MEER产出 | 胜利时的额外收益 | float | 1.2 |
| ROI | 产出/消耗比（控制1.5-2.5） | float | 2.4 |

## 二、64卦分类体系

按对战效果分为8大类，每类8卦：

### A. 攻击型（8卦）—— 强调先手、暴击、连击
### B. 防御型（8卦）—— 强调减伤、反伤、护盾
### C. 辅助型（8卦）—— 强调增益、治疗、资源获取
### D. 控制型（8卦）—— 强调眩晕、沉默、减速
### E. 爆发型（8卦）—— 强调高风险高回报
### F. 持续型（8卦）—— 强调DOT、吸血、持久战
### G. 反击型（8卦）—— 强调后发制人、反败为胜
### H. 特殊型（8卦）—— 独特机制，难以归类

## 四、对战分账逻辑（细化）

基于《势位之战》v0.1，按 benefit 值区分：

### 1. 免费模式（benefit = 0）
- 无入场费
- 无 MEER 消耗/产出
- 势位增益仅生效 50%
- 适合新手体验

### 2. 按次付费（benefit = 1）
- 入场费：1 MEER
- 卦象 MEER 消耗：全额
- 卦象 MEER 产出：全额
- 势位增益：100%

### 3. 分成模式（benefit = 2）
- 入场费：10 MEER
- 卦象 MEER 消耗：由创造者垫付 50%
- 卦象 MEER 产出：创造者抽成 20%
- 势位增益：120%（创造者加持）

### 4. 高级模式（benefit = 3）
- 入场费：50 MEER
- 卦象 MEER 消耗：全额 + 额外 50%（高风险）
- 卦象 MEER 产出：全额 + 额外 100%（高回报）
- 势位增益：150%
- **限制：MEER质押门槛 ≥ 100 MEER**（链上可执行，替代"前100名"排名限制）

**链上执行逻辑**：合约检查调用者质押池余额 ≥ 100 MEER，无需维护排名列表。

## 五、待确认问题（需哪吒/雨娃拍板）

1. **64卦 vs 8大类**：保持64卦各自独特，但势位增益统一压缩到0.95-1.15区间 ✅
2. **势位增益与对战效果的关系**：叠加计算，但有上限——基础增益×卦象特效，最终上限1.5倍 ✅
3. **权重差异化**：拆分为"基础权重(1/64) + 动态调整因子"，基于使用率/胜率动态平衡 ✅
4. **MEER消耗/产出平衡**：统一ROI 1.5-2.5倍，特殊卦也不例外 ✅
5. **卦象与卡牌属性的绑定**：随机分配+玩家自选结合——开局随机抽3卦，玩家自选其一
